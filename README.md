## 安全的小檢查

在專案根目錄逐條執行，單次最多20秒：

~~~bash
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/check_repository_health.py --check
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/check_project_status.py --check
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/export_abc_fresh_air_planning.py --check
~~~

第一條檢查公開檔案整理／連結；第二條只核對索引來源與有提供的產物雜湊，**不是畫面、工程或專業簽證**。歷史差異仍列出；若要將它們也納入退出碼，加 --include-history。不要為了變綠就改預期雜湊或重產歷史圖。

瀏覽器／WebGL、全套pytest與完整3D由屋主另開終端機驗收，詳見[工具與指令](scripts/README.md)及[資源規則](AGENTS.md)。不自動安裝依賴或背景重跑。

## 資料與目錄邊界

| 位置 | 用途 |
| --- | --- |
| inputs/project.json、requirements.json、physical-items.json | 基地／需求決策／實物資料，各有權威及來源，不由比較圖自動更新 |

| .claude/settings.local.json | 僅本機CLI權限，不進Git；[空白範例](.claude/settings.example.json)不授予任何權限 |

家庭決策與完整生活情境仍見[防漏項總表](Docs/planning-register.md)。本次只整理專案，不放寬風水、外窗、面積、照護、搬轎、法規或消防條件。

## 維護原則

只維護一份[機器入口索引](inputs/project-status.json)與上述簡短導覽。變更歷史寫入專題文件／歸檔，不再同步複製到多份README；來源、產物、屋主回報與專業簽認分開。不可直接刪被引用的凍結來源／manifest／前後備案來消除警示。
