三樓不是0人或永遠不用，這輪不刪其原用途。一二樓常用睡房現在就要有有效室外送風及關門回風；三樓先做支路／主幹條件、封口、電源及可用機位／檢修，避免裝潢後只能拆天花或鑽未知梁位。是否先買三樓主機仍待配置比較。

**若三樓劇院、閱讀、健身或客房近期就常用，該使用區應一期啟用，不因不常睡人而只留管。** 先預留只適用尚未使用的區域，並非把日常活動通風排除；配置回覆要一起列實際使用頻率。

以每人25／30／35m³/h作本輪初估，已述常住部分A約100～140、B約50～70、C約75～105m³/h；中間30假設分別120／60／90。一樓或二樓2人的夜間樓層初估50～70，C二樓1人25～35。**這些不是台灣法定通風量，也不是最後選機風量。** 背景通風、三樓／訪客尖峰、局部排氣補氣、髒濾網與實際靜壓都未含。

同一批人不在不同房間重複累加：A二樓2人是整層，不在主臥、次臥和書房各計2人。白天四人集中A客餐或三人集中C客餐時，需要相應的分配能力；夜間再分到常睡房。風量不能只按每棟總數平均撒到每層，也不能只靠客廳回風感測判斷睡房空氣。

## 各棟怎麼調整

- A：一樓客餐與孝親房各有送風；二樓主臥、次臥及書房留獨立支路。三樓客房、劇院／多用與閱讀預留；隔音門關閉時須有專支或消音回風，不靠大門縫。主機與濾網檢修避床、梯下、MDF及照護轉位。客餐回風應避烹飪污染，油煙另排。
- B：一樓香火用自己的過濾補氣與源頭獨排，不接一般ERV回收、不與浴廁／油煙共管，補氣避開直吹神桌；保留樓梯隔煙門可關。二樓主臥及安靜起居設一般新風，三樓客房／閱讀預留。全熱主機、新送回風主幹與檢修須避完整祭祀／乾背櫃保護區另合圖，不能把乾保護室改機房。
- C：一樓孝親房設專屬乾淨回風支路，客餐另有回風；二樓單人常睡房也要有自己的送風。保持已接受的前置可關門與樓梯分隔，不從開梯門取得唯一回風。二樓後小廚房／衛浴的獨排及補氣另核；三樓保留主臥及運動支路。原唯一二樓洗衣機、陽台景觀及C-AC01路線不改。

三棟可以用光纖或控制訊號協調，但**空氣系統不跨棟共管**。一樓B香火與樓上一般ERV分離；本案採乾淨區ERV回風、浴廁獨排的保守配置，沒有宣稱所有廠牌ERV都禁止浴室排風。實際可接場所要依選定機型手冊，不以通用原理覆蓋本案原有分管要求。

## 有全熱，補氣仍然要重算

| --- | ---: | ---: | ---: | ---: | ---: |
| 一般平衡ERV | 120 | 120 | 0 | 0 | 0 |
| 上述加浴室獨排 | 120 | 120 | 120 | 0 | -120 |
| 只多送10作微增送風 | 130 | 120 | 120 | 0 | -110 |
| 另有足量補氣的假設 | 120 | 120 | 120 | 120 | 0 |
| 只送新風，沒有已定排出 | 120 | 0 | 0 | 0 | +120 |

機械淨差＝室外供氣＋額外補氣－ERV對外排風－局部獨排；房間內回風或門內轉送不會多出室外風量。正差仍需要排出路徑，負差仍需補氣。這不是風壓模型，不能用m³/h直接換算Pa，也不能以淨差0就稱已完成氣密、舒適、氣味或空氣品質驗證。

B一樓香火排風／補氣量未知，不能用上層兩人的60初估替代。油煙加強也可能遠大於一般新風量，須額外補氣／聯動方案與產品能力，不能為湊風量把ERV任意改成不符合手冊的送排比例。對外進排氣要避香火、浴廁、油煙、熱泵與鄰房，依真實風向、開口和原廠規定核對，不能用示意1m就當全案合格。

先前B的兩條浴室獨排仍有用途，但已不把公共乾區氣源視為唯一待核：現在可研究由新風系統提供氣源，再核門內轉送。原400×200補氣構造仍未選定；新風不會讓關門後的轉送、阻視及聲學要求消失。**原500×300豎道只預算兩條浴廁排氣，不能再塞ERV送回風主幹或整台主機。** 新主幹若需要更多空間，仍須算面積及檢修，不降低原主臥20㎡或兩衛5／6㎡目標。

## 避免現在省、之後後悔

1. 常睡房現在就做有效送風與關門回風，不能只在客廳裝一台清淨機／新風機就視為全棟都有。
2. 保留C前置門及樓梯門可關，睡房／劇院另核消音轉送或專支回風；大門縫會影響噪音、隱私與氣味，不能當無成本解法。
3. 裝潢前確認風管、機位、濾網抽換、整機搬出及電源／控制，不能只留插座、品牌名稱或孔洞。
4. 三樓先留可用支路與檢修條件；先不確定主機台數，仍應避免日後破壞照護、隔音及完成天花才能加裝。
5. B一樓先分離香火補排與一般新風，讓煙不往樓梯、後段或樓上睡房擴散；排氣不接一般熱回收。
6. 高雄濕熱下，ERV不等於主動除濕。室外含濕量、空調潛熱、保溫冷凝與必要除濕要合算；有全熱、感測器或開窗都不能保證不發黴。

CO2與溫濕度宜能反映實際睡房使用，位置避送風直吹，不能只有客廳回風感測。濾網等級與更換取得性要和髒濾網工作點一起報價，不因過濾標示高就忽略實際風量。夜間需測風口風噪、床旁直吹及關門狀態，原廠機身噪音不是床邊實測。

MDF／IDF的設備散熱須獨立核負荷，新風與全熱不取代冷氣，也不把機櫃當房間之間的補氣／回風通道。
