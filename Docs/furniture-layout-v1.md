# 歷史 HTML 家具／設備初排 v1

家具初排顯示在 `structured/candidates/model3d.html`，用來回答「既有 HTML 想法放入一般尺寸家具後，空間是否看起來合理」。它不是現行室內設計、採購清單或施工定位。

## 第一版範圍

- 70 個 HTML 空間，共 157 件家具或設備：A 棟 27 個空間／58 件、B 棟 20 個空間／48 件、C 棟 23 個空間／51 件。
- 包含床、衣櫃、沙發、茶几、電視櫃、餐桌椅、書桌、廚具、冰箱、衛浴設備、洗衣設備、車輛、弱電機櫃與屋頂機電設備。
- 優先採用 HTML 明載內容。例如 C 棟 2F 的 L 型沙發、茶几與電視牆，C 棟 2F 的 240 cm 流理台與 75 × 70 cm 冰箱，以及 C 棟 3F 的 180 × 200 cm 雙人床與 360 cm 四衣櫃牆。
- HTML 沒寫尺寸或位置時，採一般市售尺寸及房型推排，並在房間資訊中標為「HTML＋房型推排」或「依房型推估」。

### B 棟 1F 第一版

- 神明堂：神桌、活動供桌、兩張可移動長凳與鞋櫃。日常可收合／靠側，大型祭拜時再依人數移位。
- 武轎儲藏室：武轎、法器／旗幟櫃、香燭金紙耐燃櫃、折疊整備桌與除濕機；不得作一般雜物間。
- 武轎先以收納外廓 1200 × 1700 × 1800 mm 推排，採暫定 1500 mm 完成面淨開口及直進直出。若正式門位無法形成直線搬運帶，應擴大房間／前室以容納 1800 mm 轉向圓，不能縮小模型迴避問題。
- `BbuildingView.html` 內的比例配置框會以相同家具 id、中心比例與尺寸對應 3D，測試會逐件比對，避免兩個畫面漂移。

## 如何查看

1. 以瀏覽器開啟 `structured/candidates/model3d.html`。
2. 選擇棟別、樓層與房間；選到房間後，只顯示該房家具，方便檢查。
3. 保持「顯示第一版比例量體」勾選。
4. 「示意格子」最接近 HTML 畫面格位；「標示覆寫」會優先套用 HTML 可解析的坪數或尺寸。有坪數文字的房間，建議選房後切到「標示覆寫」看家具。
5. 點選家具也會選取所屬房間，左側資訊會列出家具、配置依據與 HTML 對照文字。

洋紅色量體／外框表示家具超出目前房間格位或與同房家具碰撞。家具使用真實尺度，不會自動縮小來掩蓋空間不足。現階段部分警示源於 CSS 格位不是建築平面：例如 C 棟車庫要求兩車＋機車，但抽取後格位只有 1.2 m 深。

「沒有碰撞」並不代表動線合格。還須確認門片開啟、櫃門／抽屜、拉椅、床邊照護、逃生、設備維修與武轎完整組裝搬運的操作空間；目前檢查不涵蓋這些淨空，也不是法規或風水核可。

## HTML／3D 對應範圍

- 原 HTML 的 92 個房間格位都有對應的 3D 房間 id，可由原圖逐房進入與返回。
- B 棟神明堂／武轎儲藏室的比例家具框與 3D 共用家具 id、位置比例、旋轉與尺寸，測試逐件比對。
- A／C 與 B 棟其他房間主要對應房名、格位與文字需求；家具位置是初排，不宣稱原 HTML 已畫出相同家具坐標。
- `structured/parametric/walkthrough.html` 是不同的參數化情境，不能拿來當原 HTML 已完全同步的證明。
- 尚未配置家具的格位多為走道、樓梯、門、管道、側院、露台、神桌保護帶與維修區；不為了填滿畫面而占用。
- 討論入口新增 A 客廳、B 神明堂、B 武轎儲藏室、C 孝親房捷徑，並連到 HTML／3D 一致性檢查。

## 如何調整

可編輯來源是 `inputs/furniture-layout.json`：

- `catalog`：家具名稱、類型、尺寸與顏色。
- `profiles`：可重複使用的一組家具及相對位置。
- `rooms`：以 `棟別:樓層:HTML房間id` 對應 profile，並保存依據與 HTML 證據。
- `position`：房間內中心點比例 `[x, y]`，範圍皆為 0–1；`[0.5, 0.5]` 是房間中心。
- `rotation_deg`：平面旋轉角度。

既有大型實物不在家具 catalog 重複填尺寸。catalog 以 `physical_item_id` 連到 `inputs/physical-items.json`；目前 `B.palanquin.primary` 會提供武轎量體。實測輸入方式見 `Docs/physical-items.md`。

修改後重新產生 viewer：

```bash
.venv/bin/python scripts/export_model_3d.py
```

資料載入器會拒絕未知房間、未知家具、重複家具 id、無證據配置及超出 0–1 的位置比例，避免錯誤設定無聲消失。

## 後續限制

目前 92 個 HTML 格位中，77 個尺寸來自 CSS 推估、15 個來自文字標示、0 個來自實測，且沒有正式牆厚、門位、柱位與淨尺寸，因此本版只適合做容量與需求討論。收到建築師 R001 PDF＋IFC／DXF 並通過 preflight 後，家具需求可以延續，但位置必須依權威幾何重新配置。
