# B上層整層重排：前公衛、後套衛

2026-11-09。依屋主同意先處理B上層設計缺口，新增兩案獨立比較。原ABC／3D、第三輪基線、後門搬轎預設與無後巷前門備案各三態及149控制不改。**這次確實重排二、三樓的獨立幾何，但未併入主3D、未採用或取得工程核定。**

## 為什麼不再只微移後段隔間

舊NEW-01b在每面115mm內縮假設下主臥20.2261㎡、公衛扣0.04㎡井後4.4667㎡、套衛4.7124㎡；公衛沒有直接外窗。固定後段、完整乾保護室與各房獨立內縮的模型已有面積必要界，不能用移管或再推100mm就宣稱同時有20／5／6㎡及外窗。

本批把公衛前移到朝街端，後段改為較完整主臥＋後右套衛；一樓神桌、朝街祭祀門、乾背牆／法器櫃、庫房及既有樓梯本體保留。側界不假設有窗，公衛只畫朝前候選外窗、套衛朝後；合法開窗、有效通風、雨水隱私與獨排補氣仍待專業核對。

## 房間品質、家具與門態

主臥23.6651㎡包含更衣、梳妝與進入套衛的乾區；後左最大軸向內接矩形仍僅約14.9291㎡，不能稱整間23㎡方正睡眠核心。原1800×2000床轉向、床頭靠左實牆，原1800×600櫃、1200×500梳妝及2400mm後窗保留尺寸。套衛改由側邊進入，避免全開門切斷主臥中間通路；公衛不經主臥。

三間衛浴示意器具不縮：450×700馬桶、公衛600×450盆、套衛900×550盆櫃及900淋浴，旋轉後仍核完整外廓；操作帶可分時共享，不能宣稱同時使用、輪椅或照護通過。指定700／900方塊試線與門全開／半開／關閉分別列反例，不把全開結果套到其他狀態。

P2梯廳至茶水前室先以明確開口作比較，是否需要防火／隔煙門及完整門態仍未核；原樓梯1000名義開口也不因此被宣稱有900完成淨寬。樓梯、扶手、到達平台及火煙分隔仍需同版剖面，不能為保面積壓縮它們。

## 三樓的改進與原目標缺口

三樓公衛同前置，後段分客房與娛樂候選，完整神明堂／乾背櫃上方仍只作安靜非睡眠用途。客房扣100mm乾擋板約15.5156㎡；後右娛樂扣0.16㎡通氣井約14.3141㎡，只達原14㎡下限，**仍低於原20㎡KTV目標**。聲學牆地／浮築及門組會繼續吃面積，並未取得可用隔音構造或振動核可。

娛樂區與客房共牆、鄰近法器櫃，以及下方庫房的影響都列待核；避名義投影不等於聲學或宗教認可。客房乾擋板只阻指定中軸視線，不保證所有門開角度都看不到床；床尾約635mm，不當700mm環繞或照護空間。新沙發／桌為正常尺寸候選，非已購或原器材已容納。

三樓娛樂區也仍投影到二樓部分主臥乾區；即使沒有直接壓床體，仍可能透過樓板與共牆傳低頻。這是明列的隔音／振動代價，沒有把「避開神明堂」等同「夜間住用合理」。若聲學無法成立，保留安靜多用途方向，KTV另案且原需求不取消。

## 景觀與室外機

P2前景觀輪廓採階梯狀，面積7.156㎡；覆土投影2.52㎡約35.22%，四株木本只留示意。土深、根域、荷重、直上遮蓋、臨接、申報口徑與排水尚未核，算術不當高雄厝符合。

兩台室外機代表尺寸及各1350mm深維修預算保留，P2左機改位；700mm一般方塊路線繞土區到兩機，不把設備維修帶重算綠化。實際機型散熱、原廠拆換、冷媒長度與冷凝水仍須重排，舊線不能借用。ERV主幹與香火／浴廁／油煙保持分系統，新增前室內亦須重新核負荷。

## 前排水必須先證明成立

公衛上層400×400井只是占位預算。若直接同位置落到一樓，會新增騎樓障礙，本批明列拒絕。另一個方向是偏移回既有梯核，但所畫一樓候選仍占原梯核預留0.16㎡，必須證明實際梁板、梯下淨高、樓梯通行、防火、噪音與清掃檢修；沒有認定已找到可施工空井。

剖面表以P2作敏感度：2F+4000mm、偏移3900mm、假設坡1:50降78mm，再留50mm。結構200mm、管含支撐150mm時餘3522mm；同結構配200／250mm包絡降至3472／3422mm。若結構500mm，這些假設全部不足3500mm比較目標。P1對應直線偏移2400mm、同假設坡降48mm，但仍未證明梯核與淨高可用。坡度、包絡與結構都是研究假設，不是實際管徑或法規值，不為取得綠色結果選薄梁。

後右井位在兩個一樓版本的公衛範圍內，與列明器具本體不撞；尚未重核一樓轉位、門態與照護，不因此認定原一樓配置完全無影響。污廢水、通氣、雨水、冷凝水與香火排氣終端各自未設計；不往後巷排放、不把新風或防水當取消濕區投影的理由。

**若前室內或前排水不成立，P2就不能進入採用；應回到P1／其他拓樸或取得完整代價後再討論，不偷偷放寬面積、外窗與家規。** 原兩個入口各三態與RF快照只作保留對照；未併新排水、屋頂通氣或冷氣路線。
