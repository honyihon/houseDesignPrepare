# B屋頂設備、曬衣與新風介面同圖比較

2026-11-10。[兩張屋頂圖及新風介面](../structured/coordination/b-roof-equipment-v1/index.html)。沿R1留板帶研究作兩個獨立屋頂預留案；原ABC／3D、R0／R1／R2、Q1／Q2、P1／P2／P3、兩種一樓搬轎版本及原RF快照不改。未收到真實產品或基地資料，沒有選購、採用或施工許可。

## 本輪先處理的問題

原B-AC03／04屋頂位置對新版三樓客床合計有0.2652㎡機身投影。這不是宣稱只要有投影就必定違反家規，而是睡眠噪音／振動及維護的設計風險，原研究沒有處理到新版客床。本批把這兩個原ID、原900×350mm代表機身移到後右公共到達上方比較，不再壓列明床體；原位置保留對照，不沿用舊冷媒路線稱安裝完成。

前兩個代表槽也小幅退到115mm邊緣預算內，維持原機身及1350mm深維修輪廓；其實際身分、新購數及服務分區仍未定，**不是確認要多買兩台**。所有新位置的散熱、檢修、抗風、噪音、冷媒長度／高差及冷凝水須重核。

舊B2／B3新風1000×1600mm候選輪廓各有0.25㎡碰到本輪浴室。另以相同1600×1000mm整組包絡旋轉到乾區比較，仍留室內，沒有把非戶外主機搬上屋頂。450mm高度只是假設，檢修會占通路，濾網側抽、架梯、吊架、整機拆換及安全通行尚未核定。三樓前KTV新增服務分支與聲學消音也未因移機就完成。

## 兩種屋頂配置的取捨

| 項目 | S1前熱泵／後水塔 | S2後段水塔＋熱泵 |
| --- | --- | --- |
| 水塔／泵浦整組預留 | 1500×2000mm＝3㎡ | 1770×1700mm＝3.009㎡ |
| 熱泵整組預留 | 前側2000×1250mm＝2.5㎡ | 後側2000×1250mm＝2.5㎡ |
| 前平台 | 被熱泵多占2.5㎡ | 可保較大前平台 |
| 後設備餘量 | 水塔與後井有270mm平面距離 | 水塔貼後井，與熱泵預留只隔65mm |
| 優先核什麼 | 前熱泵散熱／聲音、前側進氣及平台代價 | 後段接管、檢修、熱回流與緊迫包絡 |

較值得先請建商核S1：分散濕設備、保留較多後側接管彈性。這不是說前熱泵已安靜或好散熱；前平台會變小，還要確認熱泵排風不影響樓下／鄰戶進氣。S2保留作平台較大的備案；零／65mm只是**包絡之間的幾何餘量**，不是原廠規定的可用間隙。兩案皆以額外100／200mm四邊放大作固定位置敏感度，遇衝突就重排，不指定小產品或縮需求來湊。

## 24㎡曬衣目標仍有缺口

RF前帶只有6000×3900＝23.4㎡名義外框，還沒扣邊緣、任何設備、門片或路線，就比原24㎡活動／曬衣目標少0.6㎡。本批分列兩種口徑：扣設備／門片後的開放輪廓，可包含共用通行；再扣700mm日常／維修試線後的餘塊，則不重複算這些路線。後者不是法規要求活動面積一定須扣掉走道，只是另看專用晾衣餘量。

兩者都可能有狹長或不連續餘塊，不能當完整可用平台，也不是合法完成淨面積。10㎡原下限未變，但不是屋主已接受縮成10㎡；面積包含哪些通路須採相同口徑再核功能，不用其中一個數字直接宣布下限通過或失敗。

沒有為湊24㎡把日常曬衣放進祭祀保護區；後側設備只保必要巡檢，後平台日常曬衣本批計0。原RF側門外也是保護投影，不能直接把巡檢路當成每天曬衣的通路。另畫RF前門直出前平台作條件案；實際梯段到達、平台、門片、防雨、防火與屋突資格未知，不修改各層樓梯或宣稱通路成立。

原三樓工作天井目標也不拿來抵RF24㎡，兩個樓層各列原需求。若未來真實條件仍不能同保，再拿完整代價給屋主決定，現在不先改需求。

## 空氣、污水與雨水各自留接口

RF後浴廁空氣出口區先留1400×1800mm，前側污氣協調區留700×700mm，後側400×400污水通氣井保原投影。這些是協調區，不證明出口數量／間距或全部支管已容納。不得把浴廁空氣、污水通氣、天井雨水及一般ERV混接，也不沿用舊公衛排氣路徑及風機工作點套新格局。

B1香火源頭排氣及過濾補氣另系統；本批仍缺它們的完整合法室外路由，未定位置不是取消。一般新風前後OA／EA備案保留，與熱泵、浴廁污氣、香火及鄰房污染的實際高度／風向關係未知；不能用平面距離作回吸合格結論。乾背保護室及既有浴廁小井不改作ERV主機房或主幹井。

## 資料到齊怎麼套

本包附`conditions-template.json`及同ID的設備CSV。`required_envelope_mm`要填廠商要求的**機身＋通風＋檢修＋接管完整包絡**，保持方向，附圖號／手冊頁。未知留null，不能填0。工具只判斷這個包絡是否小於預留，不自動旋轉、移機、採購、縮正式需求或併主3D。

先將模板另存到新的`inputs/private/`路徑，再回算到全新的私人結果目錄：

```bash
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/export_b_roof_equipment.py --conditions inputs/private/b-roof-conditions.json --output inputs/private/b-roof-recalculation-001
```

條件檔必須引用當前config雜湊；新版本不自動混入舊尺寸。有條件輸入時，輸出限新私人目錄，不覆寫公開預設或已填回覆。即使數值相容，RF前門、結構荷重、防颱、振動、排水及進排氣等人工關卡仍待專業核對。

KTV額外100mm後19.2079㎡、前量體新增10.647㎡、P3二樓前排水、天井壓2F更衣乾區防水及R1採光／乾衣問題都尚未解除。這次只有靜態幾何、來源與條件回算，沒有瀏覽器、WebGL、轉圖或工程／風水核可。
