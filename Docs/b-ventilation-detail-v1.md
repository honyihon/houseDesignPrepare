# B棟一般公衛排濕深化：補氣、檢修與建商回覆

2026-11-06。[三張深化圖與八項建商回覆表](../structured/coordination/b-ventilation-detail-v1/index.html)。延續[B外窗／排氣兩案](b-bath-ventilation-v1.md)，先完成二三樓「保房間位置」的工程資料準備；屋主尚未明確答覆是否接受無窗公衛，連續要求繼續不當成採用。

這輪修正抽風口與屋頂出口，補關門補氣、可拆檢修及構造占地敏感度。原一樓有窗照護公衛、祭祀正門、後門優先／前門備案三態、原3D及149份控制保留。原主臥20／公衛5／套衛6㎡目標不變；目前估算主臥20.0761、公衛扣污水井4.4667、套衛4.7124㎡，仍不是全部達需求的方案。

## 本輪可以先處理的問題

原抽氣口(1200,12000)靠近公衛前方補氣處，有略過後方濕區的疑慮。本輪移至(1150,12950)，水平風管繞y13600再到原主臥前臂的排氣豎道；175mm外廓避開列明床、乾保護區、武轎庫與污水管井。前方補氣與後方抽氣只是幾何方向，沒有風場模擬或實測氣流短路核可。

原屋頂兩條豎管中心僅隔250mm，只能證明管身外廓有間隔，不能證明風帽、抗風固定或維修空間可放下。這輪將兩個出風終端候選中心另排在(3850,14000)、(4850,14000)，每處圈500×500mm終端及700×700mm局部服務預留；兩中心隔1000mm不是法規、原廠安全距離或已驗證回吸間距。

新終端及局部服務預留在模型戶外設備區內，避完整祭祀乾保護區、武轎庫投影及列明室外機本體。但水塔、熱泵、進氣口、周邊窗、風雨與整條屋頂安全進出路線尚未排完；終端本體尺寸與排放方向也未知。候選屋頂管心+10350、終端+10600mm只作標高預算，不代表可穿板、無積水或能通過審查。

## 關門補氣：兩種候選由建商回覆，不先放大門縫

以120m³/h作相同條件計算，900mm理想淨寬門下10／15／20mm縫的面積為0.009／0.0135／0.018㎡，平均流速約3.70／2.47／1.85m/s。這不證明某門縫必定不足或必定吵，但不能沒有補氣／壓差測試就稱完整排風成立。

供比較的400×200mm候選開口，若自由面積比45～60%，有效面積假設0.036～0.048㎡，同風量平均流速約0.93～0.69m/s。自由面積比是分析假設，沒有用名義長寬冒充原廠有效面積；實際壓損、聲學及阻視都沒有商品證據。

- 原廠門片消音補氣候選：前牆立面x1685～2085、離地200～400mm的討論開口。須核整樘門厚、重量、框軌、把手、開啟與900mm完成淨寬，不能把名義1130mm當完成淨寬。
- 門旁牆消音補氣候選：前牆x800～1200、離地200～400mm。平面避列明盆位與門洞，但牆種、RC、完整牆厚、防火、開口與祭祀保護名義邊界的關係均待核，不先開孔。

兩處是替代方案，不是同時開兩洞湊風量。都需原廠阻視／消音構造、可清潔檢修方式及完整性能資料；普通百葉或名稱含「消音」不能當作實際隔音或隱私保證。圖中門高2100mm只為示意，沒有選門。

一般公共乾區是中間補氣來源，並不等於已有室外新風。前側候選窗關閉、兩層與其他排風同時開啟時的進氣量、負壓與氣味流向尚未設計；不能借樓梯、獨立乾保護室、其他浴廁、神明堂排煙或污水通氣管補氣，也不能用開大門才抽得動當完成驗收。

## 維修與牆柱仍是條件，不把未知算通過

每層討論風機預留箱[900,12750,2450,500,400,250]，前三值是局部x／y／相對底高、後三值是長寬高；只有盒體預留，不是已選風機。500×500mm天花檢修口[900,12700,500,500]、600×800mm梯位[800,12550,600,800]未碰列明固定器具，仍需實機拆出路線、濕區停用與安全架梯核對，不將平面放得下當真人維修已完成。

主臥豎道局部服務區[4050,13420,500,700]暫占房內通路，必須分時檢修，不能宣稱維修中仍有原900mm局部路徑。完整檢修門／耐火構造、可達高度及拆換空間都待核；沒有把檢修永久圈成新的使用面積。

500×300mm外預留內放兩條175mm外廓加50mm假設間距，需要內寬400mm。若每側包覆50mm，內框只400×200mm，寬度剛好無餘量，且要重新排管中心；每側75mm時內深150mm，低於管外廓175mm。這些不是實際耐火／隔音牆厚或核定管間距。

## 壓損只作選機前的敏感度，不指定虛構商品性能

以DN125、空氣密度1.2kg/m³、Darcy摩擦係數0.020／0.035及兩組明列彎頭／進氣／止回／風帽K係數，對90／120／130m³/h計算直管與局部阻力。完整輸入見[逐層假設表](../structured/coordination/b-ventilation-detail-v1/pressure-assumptions.csv)及[來源報告](../structured/coordination/b-ventilation-detail-v1/review.json)。這是選定假設的比較，**不是實際壓損上下界，也不是核定風機工作點**。

補氣端、另加消音器／濾網、積塵、實際管材與風帽曲線、風壓與其他排風的壓力平衡未含；長軟管不能直接沿用本模型。須請廠商提供指定風量下的P-Q曲線、噪音、外廓與可拆換方式，不能以最大無管風量代替安裝後風量，也不把既有短管候選一台套全棟。

[八項建商回覆表](../structured/coordination/b-ventilation-detail-v1/builder-response.csv)將風機、門／牆補氣、獨立管路、豎道、天花結構、屋頂、調試及報價拆開。型號、真實尺寸、證據、價格與核可欄都留空，便於同範圍比較，沒有替建商承諾原標配全含。交屋需逐間關門／開門量測，並測兩層同時運作的補氣、風口風量、止回、氣味及噪音。

有窗、抽風或RH感測都不保證不發黴；室外含濕量較高時換氣也未必除濕，防水、保溫、乾濕分區與必要除濕需另外設計。這輪沒有新增法規核可，無窗一般公衛也不能自動取得高雄厝申報資格。
