## 固定500改為有上下限的d

以原保守盒模型：`d下限 = 3704.9 + 上方安裝50 + 額外上凸e + 額外穩定餘量M - 後緣假梯底`。

M不是原上方50；它與真正所需下方空間C都留未知。表列M0只是幾何邊界，沒有替工程選餘量。板厚t150／200／250／300、e0的下限約357.102／415.861／474.620／533.379mm；每多e就同量增加下限。t300、e50、M0需583.379，不能因此直接改600。

最低末端中心預算仍為`3461.6-d`，500／550／600時分別2961.6／2911.6／2861.6。若示意管沿坡再走到後緣200mm，還要再少4；真正接頭及下凸未定，這不是整盒最低淨高。下方上限需以相同高程及扣帳口徑的C、實際下凸量再算，不能把這些預算當全室或完成面法定淨高。上下限尚未同時確定，未選d。

500須指上下游水平段間的**有效高程下降**，不是直管下料長度；彎頭造成的落差不能重複扣。四條比較線也不能當四根實管可重疊，合流總成、管徑、水力與通氣仍需設計。

上凸、前後側外擴、下凸、安裝間隔與清掃抽換各自列帳，不把上凸25當四周都外擴25。原外框距平台20，前擴25會侵入5mm；名義後移5只剛好碰邊，尚無施工餘量。
