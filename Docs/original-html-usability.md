# 既有三棟 HTML 的使用範圍

直接沿用 `AbuildingView.html`、`BbuildingView.html`、`CbuildingView.html`，不另造一套設計。原有房間位置、家具尺度、幾何属性與 HTML／3D 房間 ID 保留；需求與幾何沒有完整明確對照時，不依名稱猜測。

## 已修正與標示

- 三棟在單欄版面（1050px 以下）取消平面圖黏貼定位，避免圖面覆蓋房間說明。桌機雙欄保留黏貼圖面；列印也取消黏貼。
- 原 HTML 頁首標示版本與尺寸限制，附資料一致性查核連結。
- A 棟客廳與餐廳保留原本分開配置，兩個房間旁標示需求表的合併客餐廳是另一份待確認提案，不自動合併、移動或確認。
- B 棟武轎／祭拜說明列出操作演練問題，收納尺寸、搬運外廓與淨開口目標不混用，不視為搬運或消防驗收。
- C 棟孝親房提示床側轉位與完整照護操作；孝親衛浴不再預設向內開門，改為比較可救援開啟的門組，外部解鎖、走道與完成面淨空需設計驗收。

## 仍待確認

2026-10-05 的三棟靜態查核有 19 項警示（A 8、C 11、B 0），不是合規評分。包括文字面積與格位面積差異、屋頂設備格位重疊、外框差異及未覆蓋格位。樓層退縮、露台與留白可能是有意配置，必須先確認意圖，不照檢查器提示強制填滿或統一外框。

當前歷史 3D 有 92 個格位，其中 77 個為自動推估、15 個為宣告尺寸、0 個實測。HTML 房間連結有對應 ID，不代表量體是正式建築模型。數量與狀態會隨資料更新，以重跑查核為準。

尺寸與設備文字仍是討論起點，不以數字的精確外觀代替來源：武轎組裝尺寸、正式門位、輪椅與照護淨空、神桌跨層保護、通風補氣、防水／消防依據均需實測或負責專業確認。

## 使用與重驗

1. 在原 HTML 選樓層、點房間，閱讀用途、設備及待確認事項。
2. 點「在原設計 3D 查看這個空間」看相同格位與家具；不以示意格位確認放得下。
3. 分別討論日常、夜間、照護、節慶、雨天及故障狀態，將結論填回屋主工作台，不直接宣布情境通過。
4. 使用 `predesign consistency-review` 更新統一查核；已納入現有三棟靜態 HTML 檢查，未解警示不會因新增提醒而消失。

```sh
.venv/bin/python -m house_design predesign consistency-review
.venv/bin/python -m pytest tests/test_html_design_bridge.py tests/test_furniture_layout.py tests/test_html_consistency_metadata.py -q
npm run test:e2e -- html-usability.spec.cjs
```

瀏覽器回歸覆蓋 390／820／1440px 的三棟頁面、四層切換、說明閱讀、原 3D 深連結與列印。新說明不改歷史封存、需求確認狀態或家具量體。
