# 上層儲藏同源立體檢視

2026-11-11。接上輪[逐層儲藏平面](abc-upper-floor-storage-v1.md)，新增[儲藏立體檢視](../structured/coordination/upper-floor-storage-viewer-v1/index.html)及[可獨立解壓的離線ZIP](../structured/coordination/upper-floor-storage-viewer-v1/upper-floor-storage-3d.zip)。10版本涵蓋ABC 2F／3F／RF九個棟層，B RF D1／D2各用自己的折衣檯位置，不相加或混用。

橙色櫃體依上輪平面位置、長深及指定高度呈現，可切整層、櫃體特寫及上視，拖曳或按鈕旋轉。品名、尺寸、取物帶、保留與代價及同版平面連結直接列出。原家具、設備、房間及管線預留只作原平面投影，不補造未知高度、牆或樓梯；這是儲藏高度的空間檢視，尚未併入原ABC主3D。

選擇這個範圍是因B P4／Q3包含L形與乾保護的多邊形房界，不能用舊B矩形格局代替。檢視直接讀既有儲藏報告的同一組房界、家具占地、櫃體及操作資料，不重新求解或把不同方案拼成整棟。A／C也按相同口徑呈現，避免只有B用不同高度假設。

RF僅防雨工具收納；B折衣檯下櫃不額外占平台，原RF24㎡缺口仍未解，取物／折衣與通路分時。C3取物需進主臥的代價仍列。原衣櫃容量、兩種1F搬轎版本、家規、原房界與149控制保持；原66項需求及105項登錄不自動改狀態。

本包內含本機既有three.js r160與MIT授權，解壓後開index.html可離線閱讀，不安裝依賴、不讀私人資料或連外。若裝置無法啟用WebGL，仍可選樓層、讀品名及開同版平面。只在互動或視窗改變時繪製，沒有連續背景動畫。

檔案、同源尺寸／多邊形及簡短視角數學可在WSL檢查；不啟動場景runtime或瀏覽器：

```bash
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/export_upper_floor_storage_viewer.py --check
timeout 20s node scripts/check_storage_3d_playwright.cjs --preflight
```

顯示第2版只修閱讀與驗收：樓層選單與本版尺寸移到圖面上方；標籤按實際文字框避讓櫃體、邊界及其他標籤，放不下的名稱保留在完整清單，細線連回原物件位置。清單改為單一對照編號，預留區改中文顯示，手機可往返清單與同樓層圖面。視角按鈕回到一致角度，避免沿用前一樓層的手動旋轉；仍可拖曳旋轉。櫃體、房界、原家具及操作帶資料完全不變。
