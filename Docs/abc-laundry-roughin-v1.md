# 洗衣預埋前溝通單

2026-11-13。接[洗曬機位](abc-ground-laundry-v1.md)、[到達](abc-laundry-access-v1.md)及[晴雨輪用](abc-laundry-use-v1.md)，把給水、污水、電力、熱濕、支承和維修接回原建商／A設計師問題。[開接口表](../structured/coordination/abc-laundry-roughin-v1/index.html)／[單頁圖](../structured/coordination/abc-laundry-roughin-v1/roughin-interfaces.svg)。圖不按比例、沒有施工點位或管線路徑。

先核共用位置與合法通路，再按完整產品定點；這一輪只保留條件與核對順序。三處分開：一樓共用候選先研究A1原陽台的兩個850×750mm安裝預算；A上層另保備位，先研究A2原後陽台；C2原650×650mm機位暫不用但保空間及恢復操作。原圖與機器不拆、不增已決定啟用數量，不把備位預算當實品必能裝。

| 預埋接口 | 現在先想好 | 收到資料後再定 |
| --- | --- | --- |
| 給水／止水 | 閥件可達、漏水可處理、不被機身封住；感知或自動止水可選配 | 壓力、接管、閥位及手動操作；熱水需要依機型 |
| 洗衣污水／乾衣冷凝水 | 與陽台雨水分清，至合法污水終端；冷凝水依機型，不隨便共塞軟管 | 管徑、坡度、接管高度、存水彎／通氣、清掃及防回流圖與試驗 |

| 噪音／振動／固定 | 鄰孝親房與A上層投影保護，晾架固定與暗管避讓 | 產品支承、樓板及脫水工況；使用時段、荷重與實測方法 |
| 檢修／換機／停用 | 原淨軟水和冷氣維修不借用，A備位和C2恢復範圍不放固定櫃 | 完整開門／接管／散熱／抽換、停用端口安全防漏防臭及交接紀錄 |

乾衣先研究熱泵／冷凝式：不必然需要一般熱風排氣管，但仍有供電、散熱、環境限制及集水盒或冷凝水直排。電力排氣式保條件比較，須合法獨立排氣、補氣及棉絮清理；不接一般ERV、浴廁或油煙共管。這是兩種接口方向，不是已選機，也未規劃燃氣；未定型號前不先鑽外牆、不固定110／220V、安培、線徑、管徑、插座高度或風量。

A上層未啟用預留，與C2暫不用原機位的處置不同，均由建商／機電核止水、端口安全和存水彎防臭；不因停用而封死必要通氣或公共排水。C2保恢復使用與操作，未永久取消。共用位置未確定前，不將A後口、共同後巷或無門檻當已成立。前側810假設瓶頸、後門行程到乾衣備位20mm模型餘量、晾架占轉位及原設備維修缺口保持。
