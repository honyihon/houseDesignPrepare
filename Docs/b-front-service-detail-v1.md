# B前公衛與茶水前室 P3 深化

P3是在[P2整層重排](b-upper-replan-v1.md)上，只深化前公衛／前室的獨立比較。保留兩個直接外窗方向、原900淋浴／450×700馬桶／600面盆／1500×600茶水台，不增加前側室內輪廓，不移樓梯、主臥、後套衛、景觀或室外機。未併原3D，P1／P2、1F後門預設與前門備案各三態均保留。

閱讀入口：[P3平面、門態及完整排水](../structured/coordination/b-front-service-detail-v1/index.html)。三張靜態向量圖分別供配置、九種門態及排水剖面比較；沒有新增互動3D。

## 配置與維護

同一400×400管井後移至公衛與前室共牆處，公衛淋浴改前左，馬桶轉向靠右；茶水台移右牆，井後乾側留700×900檢修預留與700方塊到達試線。這只是檢修平面預算，檢修門高度、密封清掃口、工具／拆管與噪音尚未核；不在茶水台上方開清掃口。

同一115mm每面內縮假設下，公衛5.2860、茶水前室5.1036㎡；主臥23.6651、後套衛6.1330㎡沿用P2。管井總0.1600㎡，其中公衛及前室完成面各占0.0340㎡，另0.0920㎡在已扣的共牆預算內。房間各有一個引用，實體只有一井，沒有把兩個0.16㎡相加或把牆內管井說成不占面積。

新增公衛右疊、梯廳入口左疊的兩組雙扇門，各1130名義洞，230總框預算只得到900目標。兩扇660×45、軌間40、包絡深130mm是幾何候選，沒有實際產品。九種全開／半開／關閉組合列明；900方塊路徑只有兩門都全開才通，半開最大模型淨帶450mm，關閉為0。不能把半開當可通行，不能把候選門當消防、隔煙、外救援或照護門核可。

門片按候選雙軌畫出，不用名義開口取代門片。公衛門全開距茶水台僅25mm；梯廳門全程活動與台尾的最近平面距離約315mm，五金／把手／公差仍未核。九態實體門片占用扣除後5.0838㎡；再保守預留兩門的完整移動範圍，前室5.0640㎡，餘量有限。這不是法定面積算法。通行與茶水操作帶重疊，必須分時，不能稱兩人同時泡茶、穿行已成立。

## 排水結果與限制

偏移從3900縮為2235mm，但井後移會增加部分支管。下表以器具本體中心作假想排出口、先橫後縱的折線計長，P2也用相同方法重算；不是原廠排水口、實際管線或規定坡度。各段假設同起算高程、統一1:50，只用來暴露不利情況。

| 完整路徑（支管＋偏移） | P2 mm | P3 mm | P3假設坡降 mm |
| --- | ---: | ---: | ---: |
| 馬桶 | 5360 | 5065 | 101.3 |
| 面盆 | 6465 | 6415 | 128.3 |
| 茶水槽中心候選 | 6530 | 5680 | 113.6 |
| 淋浴 | 5250 | 3900 | 78.0 |

只算P3偏移會得3555.3mm的有利剖面；加完整路徑後，馬桶3498.7、面盆3471.7、茶水3486.4mm，低於3500比較目標。這組算式假設2F +4000、結構200、管含支撐150、檢修50；實際結構／高程／分段配管未來可能不同。結果表示**短偏移仍不能當作排水與騎樓淨高已解決**，也不是法律上已證明無法建造。表格只列2F器具至2F樓板下偏移；3F支管、立管及2F匯流／同時流量、通氣與井內容量未設計，不能借本表宣稱整棟完成。

直落1F騎樓被拒；落入原梯核的400×400仍占0.16㎡，未證明有可用空洞。新管線中心折線避開已列神明堂／乾背櫃／武轎庫投影，但實際管徑、包絡、穿梁、接管、1F梯下維修與合法終端仍未核，不以軟體結果稱全案風水通過。壓力泵／粉碎馬桶有供電、故障及保養代價，抬地坪會影響階差／門檻／樓梯，均不作預設解法。
