# B工作天井與RF維修介面比較

2026-11-10。接續Q2前側娛樂研究，優先減少工作天井造成的RF開洞及維修繞行。這是獨立續案，未採用、未併原3D；Q1／Q2、P1／P2／P3、兩個一樓搬轎版本及原RF快照均保留。[比較入口](../structured/coordination/b-working-court-v1/index.html)。

## 較值得深化的是R1留板帶

三樓工作天井仍為2400×2130mm，115mm每面假設下地面輪廓4.123㎡，由公共安靜起居區進入。RF左側保留1100mm寬板帶作維修通行，井前另留100mm護欄占位，實際比較開洞為1300×2030mm；不是把板帶當三樓多一塊面積，也不是天井增設已核柱腳。

R1少開2.473㎡，約48.38%的名義RF板洞面積，**不是工程費、雨水或漏水風險減少48.38%**。三樓整個天井仍按可能受雨的濕地面處理；部分遮頂不解除二樓更衣區上方的防水、溢流、漏水維護或家規問題。原後公衛仍對齊二樓套衛，不壓二樓主臥乾區；天井仍避床體、武轎庫及完整祭祀／乾背投影，這些平面避讓不等於全案風水核可。

本輪另發現，R0原完整開洞的100mm井前護欄占位會伸入RF祭祀保護投影0.25㎡。這不是宣稱所有護欄都違反家規，而是舊比較未核到的介面，不能默認可放。原R0資料不改寫；R1把井前護欄退回天井範圍，在指定占位模型下投影為0。護欄支承、管線及實際構造仍待正式核定。

1100mm板帶扣左緣115mm與井側護欄100mm占位，平面預算剩885mm，較700mm試線多185mm。圖中試線從RF側門外指定點出發，沒有核梯段、原門、雨天或整機搬運。護欄厚度只是預算；若改到300mm，剩685mm，700mm便不成立。900mm板帶在相同115＋100預算下也只有685mm，不當足夠。保護區只保必要巡檢通行，不放日常晾衣或機器。

保留板帶仍需建築與結構確認梁、支承、洞邊補強、護欄、淨高及荷重。現在沒有證據說一定不需支撐；若支撐落到三樓門前或天井地面，原四道門81態與地面輪廓即需重算。

## R1真正的缺點

上方直接開口縮為1300×2030mm，樓高又未定；可能更暗、更不利自然乾衣。三樓地面4.123㎡、上方板洞2.639㎡與法定有效通風開口是不同口徑。沒有畫側界假窗，也不稱這是已核工作陽台。全熱／新風不能代替合法外側、雨水排除與濕氣管理；實際需求到齊後，若此開口不成立就回比更完整開洞及護欄修正版，不能硬套R1或直接採未核的R0。

這輪沒有新增洗衣機、水槽、晾衣設備或支管產品。三樓家務內容及設備仍需和原工作陽台目標一同排入；不能只因面積算術過4㎡就說已能洗、曬、修機。

## 不開洞備案的完整代價

R2將相同三樓輪廓作**乾式折衣／收納**，不畫洗衣機、水槽或地排，RF恢復完整覆蓋。這能移除新增三樓露天雨淋地面；仍須正常屋頂防水、室內採光通風及家務使用設計。未把濕洗衣放進更衣區上方，也不會用乾區結果替未來新增排水背書。

R2的原三樓戶外工作陽台仍計0㎡，不是把室內家務房改名陽台。RF原本就有24㎡活動／曬衣目標，但未完成排位，不能同時抵三樓4㎡，更不能推定屋主接受搬上樓曬衣。這是R0／R1若遇正式條件不成立時的代價比較，尚不採用。

## 為何不直接搬天井

在本輪固定二樓、梯核、祭祀保護與Q2前帶的條件下：

- 後右原套衛115輪廓扣井僅6.133㎡，連不加新隔間的樂觀上界也放不下公衛5＋工作陽台4＝9㎡，短2.867㎡。
- 前帶娛樂基準扣井21.0159㎡，對KTV20＋戶外工作4＝24㎡已短2.9841㎡，尚未加分隔或聲學；不能默默縮KTV來換陽台。
- 將天井拉成1700×3000mm，115輪廓仍有4.0719㎡，卻和原客房重疊1.479㎡且碰原衣櫃。這不是只改天井外形就能使用的方案；需重排客房與門，不沿用原12.423㎡。

上述只是固定配置的排除式算術，並非所有整棟改法都不可能。若要完全避開二樓更衣乾區，還需重排二樓或改變其他樓層／功能，代價應另案比較。

## 屋頂不能只排冷氣

既有B-AC03／04位置、兩個前代表槽及維修包絡保留；前代表槽身分及實際購買數仍為空，沒有默認新增兩台或取代舊機。水塔／泵浦3㎡、熱泵2.5㎡、活動曬衣24㎡、梯間6㎡、無設備保護區29.5㎡的原目標逐項保留且都未取得完整排位或核可。

RF前帶23.4㎡扣兩個代表維修槽後，連不扣邊緣、走道、水塔與熱泵的樂觀餘量也只有20.97㎡，仍短24㎡曬衣平台3.03㎡。因此不能把不開洞就能「全部搬RF」當已完成解方。需求舊文字的設備座標已過時，本輪保留數量與目標，不把舊座標塞回完整祭祀投影。

本輪建議先保R1深化方向、R0通風對照及R2完整代價；等同版結構、合法戶外開口、防水溢流、RF全部設備包絡到齊再回套，不要求屋主現在接受取消陽台。KTV在每面額外100mm時仍只有19.2079㎡，前量體新增10.647㎡及P3二樓前排水缺口也都未解除。
