# C 棟孝親套衛：台灣市售高 CP 選品研究 v1

查詢日期：2026-10-22。先針對上一輪尚缺實際型號的洗手台、兩片後收疊門、折椅與右側扶手調查；不是 ABC 全屋設備採購表。本文件只新增市場研究，不改房間、HTML／3D、已驗收配置或正式選品回覆，不下單、不聯絡廠商。

## 結論與優先順序

建議先請建商以「凱撒 L2150S＋B260C、GB132N，折椅 SC102 與 Etac Relax 分別報價，兩片門另報完整門組」作第一輪選品比較。這是詢價名單，不是已經能整套照圖施工的產品組合。

- **省錢主線**：一般白色瓷盆、手動單槍龍頭、可維修的機械門；不要為造型浴櫃、感應龍頭、電動門或特殊色先增加預算。新建時一併完成補強、給排水及防水，比交屋後再鑽牆修改更值得優先列入工程範圍。
- **目前較有尺寸依據**：L2150S 的盆體平面外廓；GB132N 的標示 75mm 深度；Etac Relax 81703010 的原廠折起 80mm。都只達到部分尺寸候選，尚未完成全產品／全動線回套或真人適用確認。
- **不能硬說已找到合用現成品**：SC102 的整件折起外凸未核；兩片連動門仍缺完整濕區門組圖與完工價。名義門寬或一包五金不能代替實際淨寬。
- **建商能否「隨屋附上」是合約與採購能力問題**：可要求統包並列建材表，但不能保證原標配已含、免費升級、現貨或工程折扣。若有換標配的折抵，須分列原品折抵與新品增價。

| 項目 | 現圖／研究限制 | 選品時的解讀 |
| --- | --- | --- |
| 洗手台 | 盆體 600×450mm；頂高 850mm 是模型值 | 較小盆可列候選，不能直接縮圖取得額外通行面積；頂高、膝部、管線和操作點另核 |
| 折椅 | 目前放下 480×450mm；整件折起外凸零餘量邊界 116mm | 若討論再留 30mm，外凸上限為 86mm；應含鉸座、背板與所有配件 |
| 右側扶手 | 整件向內外凸零餘量邊界 86mm | 75mm 只剩 11mm、81mm 只剩 5mm；不是施工容差或照護合格，長度、底座位置也須核 |
| 兩片門 | 實際全開目標至少 900mm | 完整室內外凸≤165mm、洞後延伸≤910mm、全行程向洞前凸出≤60mm，只是三個方向零餘量界限 |
| 門的可選討論餘量 | 若上述方向另外留 30mm | 分別≤135／880／30mm；不是法規或原廠允差 |

原右扶手模型外凸 67.5mm，欲在原板試點多留 30mm 時只允許 56mm，連原模型也不達此額外討論值。不能要求扶手犧牲必要握持離牆距離來硬套。板試點左移僅有數值研究，未畫入原 HTML／3D，也不是救援演練。

### 預算怎麼看

L2150S 1,800＋B260C 3,800＋GB132N 4,800＋SC102 6,450＝**16,850 元**，只是這四件詢價候選公開材料價的算術小計；SC102 折起深度等條件未完成，**不是已驗證可用的成套方案或套衛完工預算**。

這個小計不含兩片門、馬桶、其他扶手、淋浴龍頭、排風、地排、防滑地材、支架錨定、管件、結構補強、防水、運送或安裝。不要再把 5700 的 8,500 元五金價格直接加上，就稱為整扇門或整間浴室完成價。Etac 的台灣公開價為系列範圍，不用最低價冒充所有配件版本報價。

## 兩片門：現階段應發規格詢價，不能先選五金就定門

VILLES 5700 是有台灣通路的研究候選，不是已核定的浴廁門。九宏頁面明寫不建議搭配緩衝拉門，玖品頁面卻列可搭 2437 緩衝吊輪；資料有衝突，可能涉及版本、配件或安裝條件。尚未取得原廠／供應商對本案具體組合的書面說明前，不合併宣稱相容。

玖品另列 2437 雙邊緩衝吊輪 6,500／組、2210 吊輪 1,250／組、2469 軌道 80／尺。這些是個別零件資訊，不代表全部必買，也不是兩片門完整用量表。不要任選便宜配件混組。

[Villes 原廠網站](https://www.villes2000.com/)部分技術資料需申請存取；本輪不申請帳號、不聯絡原廠。未取得可核對的完整系統圖前，濕區耐蝕、防夾、外解鎖、維修方式與各方向包絡保持未知。可請建商另提其慣用完整門組，按同一條件比較，不綁死此進口五金。

詢價需同時提供：

1. 兩片同側後收疊、無地面突出門檻的構造方案；不能用一片固定一片活動的普通雙扇淋浴拉門替代。門片材料須說明濕區適用性，避免只以「防潮」代替可承受的實際用水環境。
2. 含框、把手、鎖、同步器、軌道、止擋與檢修的全開／半開／全關剖面與平面；實際淨開至少 900mm，並核對前述三個方向界限。
3. 廠商說明門片外側緊急解鎖、故障／倒地受壓時處理方式、開關施力、夾指保護及防脫落。不能只說「拉門不會卡人」。
4. 完整門組材料價、安裝與補強價、維修可達性、替換五金供應、保固範圍及工期。防火等級若有要求，另提適用認證，不用本研究當核可。

## 後續如何回套，不假裝已選定

1. 本文件先供屋主比較與建商報價。公開網頁尺寸只是市場線索；商品資料有缺項就保留未知，不用模型值補空。
2. 收到完整施工圖、版本及明確回覆後，再與來源、日期、雜湊一併登錄[正式商品回覆檔](../inputs/c-care-bath-products.json)。**本輪維持四個商品身份與 16 項尺寸空值**，不把這份自行整理的市場研究冒充原廠核定文件。
3. 將候選產品的實際形狀、支架、配管、門片全行程與錨座同步回套 HTML／3D，保留原版作比較；重新檢查到位、操作、轉位、折椅和門的分時狀態。尺寸更小不等於能自動置中洗手或減少原 250mm 偏側。
4. 如無法在合理產品及安裝公差下使用，另提局部整合調整，不為保住原圖而強行削減通路、承重或握持空間。產品、法規、風水、照護及救援的確認各自保留，不互相代替。
