## 本輪能先完成的事

1. 衛浴不把120×120cm淋浴硬塞上段窄腿，改放下段左後；45×70cm便器放右後、60×45cm洗手台放上段。設備在80／100／115mm三個假設內縮下未撞界或其他設備；這只是座標結果，不是照護功能成立。
2. 實畫150cm轉位、90×120cm便器側移與操作地面。轉位借用淋浴地面，故只討論零門檻、可移浴簾、不設固定玻璃的排法；扶手、坡度、膝下淨空、側移與協助者站位仍需選品／實演。
3. 正門內側至公共衛浴的900×900mm討論本體先在前廳轉入側緣，避免穿過祭拜暫留帶。另檢到洗手台、便器側移與淋浴的分支；上段洗手台需倒退回下段轉位，不假裝上段也有150cm圓。
4. 洗衣機650×650mm、一般洗槽600×600mm改靠後牆，使家務入口先有轉向地面，再到兩組操作位置。候選後窗窗台改120cm，避免先被設備遮住；外窗權利、有效換氣、防雨與排水尚未核，不能保證不生黴。
5. 前／後門搬轎各依自己的起點、門洞與儲藏位置做室內本體平移；保留120×170×180cm暫估本體，不拿收納尺寸當裝桿／人員外廓。前門案不借用後巷，後門案不宣稱已完成前門備案驗證。

## 沒有被藏起來的衝突

| 項目 | 細排發現 | 本輪處理／推薦 |
| --- | --- | --- |
| 約1m家務通道的祭拜區轉彎 | 即使兩張長凳先停放別處，保留原供桌仍撞桌 | 原位置保留作控制組；另外比較後移22cm、貼神桌前緣，不改神桌或正門中軸。是否可貼桌須問家中。 |
| 兩張長凳 | 日常清路後，停放位置沒有完整坐席腿部空間；祭祀擺成可坐兩列又占家務通路 | 全尺寸保留，不虛構收折厚度；平日停凳不算座位，祭祀移位並停止家務穿越／搬轎。搬凳及旋轉過程未驗。 |
| 原神桌後方餘量 | 原位僅留80mm；100／115mm假設內縮會少20／35mm | 明列神桌座標衝突，不暗移神桌、縮桌或調薄牆；供桌後移案也不能因此稱全情境成立。牆柱與完成面確認後連同桌位一起核。 |
| 衛浴原拉門 | 在現右側門位，表面滑門往北跨乾櫃入口、往南跨儲藏門口 | **原拉門需求保留、門型未解**。應先由建築師整合門洞／牆袋／門廊與乾櫃入口；不先用外開門替換。 |
| 倒地救援／外開門比較 | 單扇外開占側緣太多；假設兩扇各500mm、厚45mm時，115mm情境只餘905mm，比900mm本體多5mm | 不是可下單的產品或可接受餘裕；雙扇也不符合原拉門需求。倒地範例阻斷正常進門線，拆門、緊急解鎖、施救操作仍未知。 |

| 儲藏／工作區面積 | 80mm時儲藏9.6404m²；115mm時9.0965m²。工作區在115mm時4.8351m² | 原儲藏10.5／工作區5m²目標不變，未達仍記未達；不能因同意細排而自動改需求。 |

## 需要決定時的最佳方向

- 家規：供桌可否貼神桌前緣？**建議只在家中接受貼桌、平日停凳／祭祀移位且可中斷家務的前提下保留此方向**。若不接受，不縮供桌硬通，應回到祭祀區／後段整體重排。保留原控制組，不需現在猜答案。
- 門型：**建議維持原拉門與900mm淨寬目標**，先做門位與乾櫃入口整合；不建議因平面看似有縫，就同意只有5mm討論餘量的雙扇外開。若確需改原門型，需屋主與照護／消防專業另確認。
- 儲藏：本輪只細排9.64m²方向，**不建議現在把原10.5m²目標刪掉**；有柱位、實測武轎與完整搬運外廓後再取捨。
