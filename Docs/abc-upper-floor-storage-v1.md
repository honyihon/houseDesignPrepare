A公共走道不置櫃，原540cm衣櫃及240cm淺櫃保留；3F實際沙發床展開須連商品再核。B不占主臥、兩衛、KTV聲學面積、獨立乾背室、機電櫃或搬轎路線；安靜區只存輕量乾燥備品，不新增濕設備、震動電器或家規豁免，後門預設／前門備案都保留。B RF24㎡缺口仍存在，折衣取物與通路沿原提案分時。

C2不擠洗曬、景觀、IDF或樓梯；唯一洗衣機仍在2F。C3公共取物需進主臥，是這個最小改法的代價；目前通道與運動安全區不拿來放櫃，若日後要求全樓共用入口，需連家具與門位另比。RF只存耐候工具與備品，不當棉被、衣物的室內乾燥儲藏；抗風錨定、防鏽、防雨、結露、排水、維修與荷重另核。

儲物本體及操作帶已在同源2D資料檢查房界、原家具／操作、列明門前及機電預留、既有試線；這是指定幾何篩檢，沒有真實櫃內有效容量、門片全掃掠、全程搬入取物或專業核可。新櫃體還未併主3D，原3D與本輪的新增物件須分開看，不能沿用舊版畫面passed。

圖例改善沿既有家具title及冷氣內／外機資料，把編號、中文名稱及代表尺寸放在可見圖例，不再只靠滑鼠提示。新儲藏圖也列所有家具、設備及機電預留的中文名稱；機號仍是追溯代號，不是已選機型。舊圖保留作原始來源，交付閱讀副本加圖例，不更改房間或家具幾何。

新條件記在inputs/upper-floor-storage.json，來源為當前C樓梯整合快照、B P4、Q3與兩個Q3 RF版本；資料版次分別標示，不宣稱它們已完成整棟合圖。原66項需求與105項登錄仍依原檔狀態顯示；此次新增的屋主儲藏要求有明確紀錄，日後正式任務書／圖面要一併核對，不因研究櫃表就自動改需求決策鏈。

```bash
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/export_upper_floor_storage.py
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/export_upper_floor_storage.py --check
```

其後依序更新project-next-steps、builder-communication與design-discussion-basis。瀏覽器／WebGL及主3D重建留待屋主另終端機執行，不自動啟動；本輪只生成小型向量圖及檔案／局部幾何檢查。
