# A/B/C 棟設計修正需求檢核包

更新日期：2026-04-28  
目的：將 A/B/C 棟設計建議收斂成可開會、可追蹤、可後續改圖的檢核文件。此文件不代表法規或結構已通過；涉及採光、通風、逃生距離、樓梯尺寸、RF 載重等項目，均需正式圖說與專業技師確認。

## 使用方式

1. 設計會議先看各棟「10 條會議議程」。
2. HTML 修改前，先處理狀態為 `缺漏` 或 `部分涵蓋` 的第一優先項目。
3. 狀態為 `需專業計算` 的項目不可由 Claude Code 宣稱通過，只能列為正式計算、審圖或技師確認任務。
4. 後續若要改圖，先從 A 棟第一優先缺口開始，再跑：

```text
/workflow-house-all-in-one inputs/design_request.md --mode concept --buildings A --selection auto
```

## 狀態定義

| 狀態 | 定義 |
|---|---|
| 已涵蓋 | 現有 HTML 已明確描述該需求，後續主要是施工圖或專業確認 |
| 部分涵蓋 | 現有 HTML 有方向或局部文字，但仍缺詳圖、尺寸、路徑、驗收條件或責任分工 |
| 缺漏 | 現有 HTML 未找到足夠描述，後續可由 HTML 文件或圖面補強 |
| 需專業計算 | 必須由建築師、結構技師、水電、空調、消防或室內設計專業計算/確認 |

### A 棟 10 條設計會議議程

1. 後陽台動線改成廚房/餐廳可直達。
2. 1F 公衛門對餐廳的視線與門向修正。
3. ERV、排風、油煙管路與套管位置定案。
4. 樓梯尺寸、扶手、平台、止滑、照明與逃生路線正式檢核。
5. RF 水塔、熱泵、VF800、太陽能設備載重由結構技師確認。
6. 熱水回水管與循環泵電源預留轉施工圖。
7. MDF 防水、散熱、隔音、維修淨空確認。
8. 採光與通風面積正式計算。
9. 外牆與屋頂隔熱規格補上。
10. 太陽能、EV、儲能先預留，但 RF 空間與維修路徑要先排好。
