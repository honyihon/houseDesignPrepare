## 現行、歷史與QA分開

唯一機器入口為[inputs/project-status.json](../inputs/project-status.json)。目前列7個現行包及6個歷史包；資料來源、可選產物manifest、屋主回報與原始QA分開。

- 現行入口：條件式預先規劃、高雄厝／C整合、新風三批及B家規／排氣研究。
- 歷史對照：2026-10-20整棟、舊B一樓、舊C局部／選品、C概念合圖快照及原ABC；不再搶占預設入口。

- 檔案／來源相符不等於瀏覽器畫面、法規、高雄厝資格、風水或施工核可。需要畫面驗收時，由屋主另開終端機跑專用CLI。

~~~bash
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/check_project_status.py --check
timeout 20s env PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B scripts/check_project_status.py --check --include-history
~~~

第二條將歷史差異也納入退出碼，預期可能exit 1；不是要求現在重建所有歷史圖。完整操作見[工具指令](../scripts/README.md)。
