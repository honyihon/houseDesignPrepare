# ABC同範圍報價核對

2026-11-11。下次收到報價，先看[核價六步與12組漏項提醒](../structured/planning/design-discussion-basis/decision-sequence.html#quote-review)，沿原[same-scope-quotes.csv](../structured/planning/design-discussion-basis/same-scope-quotes.csv)記錄。這輪只補原表與閱讀指引；沒有真實價單、採購、付款比例或需求取捨。

## 先比同範圍，再談價格

1. **核估價版本。** 寫明廠商、價單編號及日期／有效期、幣別、方案／狀態、棟層、圖號、所據文件與SHA-256。過往網路市場價不當本次建商有效價。
2. **對齊數量與完整安裝。** 型號與配對、數量單位、材料、工資、配件、電源排水、吊運清運、測試調試及交付都要查含不含。型號相同仍可能安裝範圍不同。
3. **分原價、折抵、差額及替代完整價。** 寫原契約或基準價依據；若是已扣折抵的淨追加，就不再扣一次。稅費、數量及原新作法需同口徑，原檔保留。
4. **排互斥與重複。** 各完整方案獨立列比較組。每筆重疊工程只選一次計價歸屬，其他包明列已含／排除；共用進線、吊運或測試若有分攤，寫依據，不能每棟再收整筆。
5. **核交期與責任。** 查有效期、交期、付款里程碑及應交成果、替代品核對、複驗、保固起算及修復分界。缺貨不能只寫同級品就換，尺寸、性能、安裝及完整價差要重核。
6. **留下待件與決定。** 概算可先談；缺資料的項目列待核及議定窗口／期限。收到價單、屋主選擇、專業核對與正式發行分開，受影響預埋另對工序。

先辨認「基準總價／增減差額／替代完整價」，再決定是否能算：只在同幣別、同稅費、同棟層與完整範圍且無重疊時，才人工比較基準價與新完整價，或將確認過的淨差額套回基準。替代完整價不能再加原價；未知、暫估、未選方案不當0或直接相加。工具不自動算全案總價。

## 同一張表如何放不同廠商及替代案

Q-01～12仍是估價議題ID；同一議題可有多家廠商、多版價單或多個替代案，所以不是唯一列號。原表新增八個空白欄：

| 欄位 | 記什麼 |
| --- | --- |
| 報價比較組ID | 相同棟層、功能品質、範圍與稅費口徑的比較組；條件未對齊先另組或列待核 |
| 報價列ID | 每家、每方案、每版價單各一個唯一代號；保留原Q議題ID，多項明細可另附同列ID |
| 原契約或基準報價版次 | 寫明比較哪份原價或契約範圍，不猜折抵 |
| 估價依據文件及SHA256 | 原價單、依據圖面與附件可追溯代號及雜湊；雜湊只辨認指定檔案，不驗證內容或承諾 |
| 費用口徑（基準總價／增減差額／替代完整價） | 說明原「同範圍總額」是哪種金額；尚未確定就留待核 |
| 互斥替代組ID | 例如B入口兩版或新風兩系統，同組不全加；具體方案仍填原方案欄 |
| 重複工項及一次計價歸屬 | 哪份／哪列已含門組、電源、排水或測試，其餘如何排除；原始價單不改寫 |
| 跨棟共用工程與分攤依據 | 共用工項的總範圍、一次計價位置、各棟分攤依據及是否已含，待議不填0 |

原型號、數量、工料、折抵、稅金、不含項、總額、付款、保固及選擇欄保留。廠商原始報價與內部同範圍對照分開保存；對照時調整了哪些口徑須寫明，不把人工正規化數字冒充對方原報價。
