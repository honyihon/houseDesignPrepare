## 這版怎麼改

以原兩片門組的全開快照為控制，不再以最早單片門版當底。保留2.4×3m、7.2m²名義套衛與6×17.63m全棟框；115mm每面扣除是假設完成面預算，不是實測牆／門框。原900mm身體矩形、1500×1800mm預留、1500mm圓及700mm設備操作目標不降低，也不當成法定核可尺寸。

1. 同一600×450×850mm壁掛盆轉向左牆，平面外廓改450×600mm：`[3715,13915,450,600]`，旋轉270°。不是換較小盆。原模型170mm可見盆實體與700mm操作深度保留，檯下膝部通行信用仍0。
2. 臥室與浴室兩側配對門洞再後移150mm，中心y=15175mm；較最早原洞共後移350mm。名義門洞1200mm、兩片各660×45×2100mm、60mm搭接與原把手／軌距／止擋預算不縮。
3. 盆前900mm矩形以`[4665,14465]`為最後中心，面向左側盆緣到位，與盆中線偏側250mm；不假裝置中或已核坐姿可及。若在同一盆前距離對齊盆中線，900mm矩形會越過前完成面，並碰原掀起扶手與求助繩；這個反例保存在`centered_basin_control`。
4. 原馬桶求助繩會落進旋轉後的700mm操作區，候選向右移200mm，x=4750→4950mm。沒有刪除或縮小拉繩；低位可及、防纏繞、聲光／手機及離線備援仍待核。
5. 剛性板入浴試線隨門洞後移150mm；轉向試點由`[4850,15670]`前移到`[4850,15620]`。1800×600mm板與1898mm全對角保守方框不縮，沒有把它當真人擔架或抬抱演練。

門洞兩側的接近預留依實際新洞重新計算，不能只把舊門圖示或其中一側的預留平移；臥室前端的另一道入口不跟著移。

## 數字改善與交換代價

以下都是指定平面外廓的方向性餘量，不是商品／完工實測或使用核可。盆轉向後改沿其真正面向的x軸量距，不能仍套舊y差公式。

| 項目 | 原兩片門組控制 | 側牆盆比較 |
| --- | --- | --- |
| 盆前指定900mm到位點至盆緣 | 0mm | 50mm；偏側250mm，坐姿可及未核 |
| 馬桶側移預留至盆體 | 15mm | 165mm |
| 剛性板轉向至收起折椅 | 8.5mm | 58.5mm |
| 停門含20mm止擋後至後完成面 | 350mm | 200mm，減少150mm |
| 門片／把手完整行程至盆體 | 30mm | 30mm，未改善成大公差 |
| 板轉向至右側扶手 | 18.5mm | 18.5mm，仍緊 |
| 130mm門組厚度至轉位預留 | 35mm | 35mm；165mm厚即0，180mm厚侵入15mm |

新盆前矩形距前完成面100mm、距掀起扶手沿y方向32.5mm；板轉向前緣到馬桶後緣56mm。改善三個舊數字，不代表每處都寬裕。方向性「單項再消耗20mm」時，右扶手側18.5mm會變−1.5mm；這是保留的風險，不是裝修容許誤差或所有公差同時套算。

盆前原700mm操作區`[4165,13915,700,600]`與馬桶側移區重疊0.2675m²，必須分時。全開的新門片與操作區不撞，但不能宣稱兩人同時洗手／側移或雙人抬抱足夠。原門組控制在半開、全關時另會占用盆前操作與到位區，圖上以紅色反例保留；新案能幾何容納操作區，也仍不可穿越半開／關門入口。

- 後600mm高窗及830mm戶外通風帶不動、不改室內面積。外窗不證明合法開窗、有效換氣或免除機械排風／補氣。
- 1500×1800mm與1500mm圓仍借淋浴濕地，只在折椅收起、扶手掀起等指定狀態比較；不是獨立乾地轉位、洗澡／側移同時通過。
- 套衛仍須穿臥室，公共直達照服偏好缺口保留。門外解鎖／拆卸、倒地施壓、移位機、照護人數與真正輪椅轉向仍未知。
- 盆轉向有給排水與壁掛補強代價；不預設可鑿柱、梁或承重牆。防水接續、門軌支撐、同步／防夾、排水坡度與商品全包絡待設計師／門廠確認。
- 盆前偏側使用能否接受，需先以實物／足尺樣板確認坐姿龍頭操作與排水管避讓；若不行，優先再比盆位／馬桶前緣整合，而非降低900mm或偷偷縮盆。本包不替屋主採用、不核定宗教或家庭偏好。
