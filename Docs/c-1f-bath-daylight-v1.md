## 建議討論順序

如果優先解決訪客如廁與長輩隱私，先評估方案 1，因為不減少原客餐廳面積；但淺前室、鞋櫃、客廳採光及前段糞管仍是代價。若優先要日常客廳靠前側開口，先評估方案 2；代價是客餐廳合計由 27.2m² 減為 22.4m²，餐廳借光及內部公衛排氣另解。**沒有一案已全面達標，不建議此時定案裝潢。**

1. 屋主先排「訪客隱私、客廳採光、餐桌人數、鞋櫃、入口照護」的優先順序；比較頁選項不自動記錄成需求決定。
2. 地籍及道路資料到齊後，建築師逐筆確認可建範圍、騎樓／退縮、有效採光／通風及前後開口；不以三筆總面積代單棟試算。
3. 水電與空調確認新增濕區、排氣、排水、管路／穿孔及冷氣型號，保存圖面、來源與查核責任。
4. 室內設計師用完成面淨尺寸、實際門框、鞋櫃／桌椅與輔具做入口、夜間如廁、換鞋、救援及家具搬運演練；不以輪椅方框代替測試。
5. 屋主選案並取得必要專業證據後，另行正式修改主案與需求紀錄，再同步生成 ABC HTML／3D、立面及相關檢核。不得先把比較案標成合規或可施工。

風水以不穿臥室、公衛入口偏向乾區、隔音／防臭及私密性作可討論條件；實際坐向、宗教偏好與顧問判斷未取得，不宣稱風水核可。
