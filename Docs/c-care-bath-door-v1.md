## 建議方向及這次確定發現的問題

推薦先研究「門洞向後移200mm、原1200mm名義寬不變、兩片連動共同向後收疊」。不移隔間位置、床、盆、馬桶或淋浴。不先借臥室或後側戶外通風帶。

原門片閉合為 `[3715,14195,95,1260]`，原盆體為 `[3715,13915,600,450]`；閉合門片與盆體在平面上重疊170mm。這是本輪新增的全行程／固定物檢查，不能被父版「全開時試線無衝突」的結果掩蓋。即使只把單片門洞向後移200mm，也會令停門含20mm止擋後短缺220mm，不能只移門洞就宣布解決。

| 項目 | 原單片控制 | 兩片後收疊比較 |
| --- | --- | --- |
| 門洞中心y | 14825mm | 15025mm，兩側配對門洞均後移200mm |
| 門洞／目標 | 名義1200mm，原900mm目標不降 | 同左；實際框、把手損失未知 |
| 門片 | 原1260×95×2100mm完整包絡 | 兩片各660×45×2100mm，閉合搭接60mm、合計覆蓋1260mm，不是縮門洞 |
| 連動 | 原片平移1230mm | 主動片1260mm、從動片630mm，假設2:1線性同步，實際機構未選 |
| 兩片總厚 | 原95mm包絡 | 45＋15軌道間距＋45＋25把手＝130mm假設；未核吊輪、外側把手與補強 |
| 全行程到盆體的方向餘量 | −170mm，存在實際模型外廓重疊 | ＋30mm；仍須含商品、公差及防夾設計 |
| 停門後端，另扣20mm止擋／檢修預算 | −20mm | ＋350mm；真實維修／止擋依原廠圖核 |
| 全開、半開、全關可用開口假設 | 970／470／0mm | 970／485／0mm，後兩者不得通行 |

「970mm」是1200−2×115mm的討論扣框值。115mm是綜合假設，不是實測門框寬、牆厚或外側把手包絡；沒有授予實際900mm通行核可。

兩片全開時前緣分別15655、15625mm，尾端分別16315、16285mm。收疊不是兩片縮成一片，也不是瞬間消失；主動片把手隨門片一起平移。20mm止擋預算從較長片尾端16315mm後算至16335mm，距假設後完成面16685mm餘350mm。

## 厚度不能忽略：只移討論標示，不移設備

兩片較短不代表更薄。130mm總包絡會侵入原轉位位置，因此新比較：

- 1500×1800mm完整矩形由x=3810右移到3880mm，尺寸不縮。
- 直徑1500mm圓的中心由x=4560右移到4630mm，圓徑不縮。
- 600×1800mm剛性板的入浴支線及轉向中心右移50mm；1898mm全對角保守轉向方框不縮。它仍不是擔架、真人或抬抱人員的救援驗證。
- 原兩個600×600mm單名照護者候選站位及到位支線保留；不是雙人抬抱、力量／可及或同時照護通過。

新標示到門組總厚的方向餘量：130mm厚時35mm、165mm厚時0、180mm厚時侵入15mm。不得任選兩片門；若實際產品超出預算，需重新回套整個轉位與動線，不可只改報告數字。

原位置被門片侵入的證據獨立保存為`original_turn_position_door_conflicts`，不會因新位置可容納而刪掉。全行程掃掠以線性平移的解析聯集計算，不只核開／關兩個端點；門片／把手掃掠仍與入口矩形試線重疊，操作前要讓出掃掠區，不能把輪椅／人留在其中。

## 重算範圍與仍未完成的條件

每種門組各有全開、半開、全關三個獨立狀態，共六個；全部以父版折椅收起／馬桶扶手掀起為底。重新計算騎樓內點至床、床至浴室、三件衛浴的指定900mm矩形到位、600mm照護者支線、轉位矩形／圓、馬桶側移及剛性板平移／轉向。

半開／關門必須實際被其門片阻擋；保留床的騎樓試線不能跟著被破壞。圖上入浴線在受阻狀態改紅，不沿用父版的綠色線。

新入口橫移試線距盆體從10增為210mm，但盆前最後到位點仍0mm、側移預留到盆右緣仍15mm、剛性板轉向到收起折椅仍8.5mm；本輪不是整套浴室公差問題都解決。原三件設備與700mm操作、前公衛、IDF、後600mm高窗、830mm戶外通風帶及上層均不動。原套衛仍需穿臥室進入，公共直達照服偏好缺口保留；C仍只有2F既有一台洗衣機。

轉位仍借淋浴濕地分時使用。本輪沒有疊加折椅放下、扶手放下、倒地救援或洗澡狀態，也沒證明真人輪椅運動學、門組外解鎖／外拆卸、雙向把手可及、防夾／斷電、承重、排水防水、法定換氣或消防符合。

下一份應向門廠取得的資料：完整框／軌／吊輪／同步器剖面、兩片真實全開及停放包絡、把手雙向凸出、止擋與維修條件、零凸起地軌候選、濕區耐蝕、門外解鎖及倒地時門外可拆程序。拿到產品圖後再核尺寸，沒有預設品牌型號或替屋主採購。

## 驗收與資源限制

新包預期2方案／6狀態／24樓層快照／234分區次／300家具次；是同一棟C的六組快照，不是新增300件家具。每個狀態8件原衛浴工程配件、原單片另1項止擋預算、兩片另2項止擋／把手預算，皆非已購實物。

前端測試技能用於同源房間／門洞／門片／把手／試線、未採用警語，以及手機實際三件衛浴本體的像素與設備清單往返。Browser插件未提供，依屋主資源規則不自動啟動瀏覽器、WebGL、全套pytest或整套3D runtime。

27項Python及6項JavaScript小範圍測試通過；JavaScript只編譯腳本、核驗資料和極小的止擋／把手網格，不啟動Scene或WebGL。新頁畫面仍`rendered_qa=not-run`，必須取得同來源新結果並另看截圖。
