# B三樓Q3：L形KTV與上層樓梯重分比較

2026-11-10。[整層、樓梯與面積敏感度](../structured/coordination/b-ktv-stair-options-v1/index.html)。本輪把KTV20㎡原目標放回完整樓梯／聲學空間一起比較，不再只挑薄隔音層湊面積。Q3是獨立提案，未採用、未併原3D；Q1／Q2、原樓梯及RF各版本保留。

## Q3確實改善什麼

KTV前帶保6000×3900mm，再向左後方原梯核延伸2400×800mm，形成L形。名義房間增加1.92㎡，原梯核相應減少；**整層沒有比Q2增加建築量體，仍在6000×17630研究框內**。Q2本來就需要正式核定的前側新增10.647㎡室內量體仍是先決條件，不是已核可建量或允許交屋後封陽台。

右側完整神明堂／乾背保護投影保持原樣；二樓主臥／兩衛、三樓後客房／有窗公衛／工作天井的房間輪廓、床與器具均不改。一樓祭祀朝街正門、神桌、搬轎後門預設／前門備案、武轎庫與一樓樓梯位置尺寸也不改。上層結構可能傳回梁柱，這不等於保證一樓施工完全不受影響。

| 面積口徑 | Q2原前帶 | Q3左後延伸800mm |
| --- | ---: | ---: |
| 名義KTV輪廓 | 23.4000㎡ | 25.3200㎡ |
| 四邊115＋額外100mm並扣原管井 | 19.2079㎡ | 原管井不消失，另核包覆 |
| 同上，井外另留每面50mm、再扣0.54㎡機櫃 | 18.6129㎡ | **20.1889㎡** |
| 與20㎡目標差額（最後一列口徑） | 少1.3871㎡ | 多0.1889㎡ |

0.1889㎡餘量很有限，不能稱完整隔音KTV已成立。四邊額外100mm是空間敏感度，沒有dB或材料承諾；樓板、天花、門窗、內部管井、浮築、聲閘、消音支路與低頻振動都未選定。

新增可用部分主要是左後入口凹部與通路，原沙發／桌位置仍相同。這不是無柱20㎡矩形大廳，也沒有證明多了座位、觀影距離或可唱人數；不能只看合計面積認為活動主區等量變大。

機櫃600×900mm只是占地預留，非選機；沙發1800×900、桌1200×600與螢幕1000×80保原尺寸，螢幕向室內退100mm以免貼到較厚完成面。機櫃操作和入口動線共用，維修不得堵唯一門路。沒有把上方消音器當已核產品，也未把未排完的器材需求算成0。

## 樓梯代價，不能只把梯廳框縮小

來源一樓高4000mm、24級；二樓至三樓及三樓至RF各高3000mm、18級。Q3保一樓原梯，改的是兩段上層梯的前後分配：

| 項目 | 原上層梯 | Q3研究 |
| --- | ---: | ---: |
| 梯段數／級數 | 雙折、18級 | 同原 |
| 每跑名義寬 | 1000mm | 同原 |
| 踏面 | 270mm | 同原 |
| 單跑水平長 | 2160mm | 同原 |
| 折返平台深 | 1900mm | 1100mm |
| 前端位置 | y3970 | y4770 |
| 後端位置 | y9030 | 同原 |

1100mm只比本輪1000mm比較下限多100mm；不是實際扶手、完成面或法定平台已核。名義踏高仍約166.67mm，來源層高也是設計假設。實際梁底、梯井、防火、扶手、樓板及頭部路徑都需正式剖面。

二樓到達的處理尤其重要：一樓上來的右跑末段仍在原位置。如果照新上層梯位置直接鋪2200×1000mm全寬平台，會壓到原末段三個踏步；200mm板厚示意下，局部淨高甚至出現負值。**這個矩形鋪板做法被排除。**

Q3保留二樓原前平台，再沿左側接到後移的出發平台，形成L形平地；右側原下樓梯洞保持。列明900mm方塊可在這個L形平面內轉接。新增左接段下方與原左跑的少數踏步，在200mm板厚假設下局部最小3300mm；這只覆核這幾個局部，不是整座樓梯淨高核可，更沒有真實梁／頭部運動驗證。

三樓入梯與出梯改成同一後移位置；RF到達也會後移800mm。原屋頂R／S／D研究不因此自動有效，RF前室、前／側門與維修通路須另回套；本輪沒有把舊屋頂passed貼到新樓梯上。

## 門與新風一起列代價

KTV門改比1330mm名義洞，215mm兩側完成面預算後剩900mm；只代表本輪幾何預算。一般900mm到達方塊可由新平台進到KTV指定空地，沙發操作仍用700mm普通試線，不能當全室輪椅迴轉或實際聲學門核可。

原三樓梯核側門中心y4400會落在新增KTV邊界，不能留下聲學旁通。本案移到新平台側邊、中心y5270；與KTV門各自開／半開／關閉共9態。前後門能否有合適防火、隔煙、隔音性能及自閉控制，仍需整組產品／消防回覆；**樓梯沒有被當成已核雙門聲閘**。

一般新風需獨立的KTV送回風、關門消音及檢修。不可靠開梯門、門下大縫，也不把B一樓香火、浴廁污氣或污水通氣接入一般ERV。實際風量、壓損、消音器、外口及室內主機分配未因面積改善就完成。

## 哪些情況仍會失敗

- 同一Q3加到額外150mm／面，保50mm井包與0.54㎡機櫃後僅19.2399㎡，仍未達20。
- 即使延伸900mm、把折返平台壓到本輪1000mm比較下限，額外150mm時也只19.4269㎡；不能拿900mm當穩健解法。
- 額外100mm時，若實際要扣1㎡地面服務空間，800mm延伸僅19.7289㎡；雙門聲閘、器材或其他地面占位必須另列，不能說已留足。
- 正式結構若不允許上層梯改、L形平台／板洞或門位，Q3就不能整套採用，Q2原梯與原20㎡需求仍保留。

因此先把Q3留作「可能保20㎡但牽動上層梯」的完整代價案，請建築、結構、聲學與機電在同版條件下核對；不在資料不足前替屋主選薄隔音層、縮KTV或犧牲客房／外窗／祭祀。

P3二樓前排水、天井在二樓更衣乾區上方的防水、R1採光乾衣、RF24㎡容量及全設備問題仍在。這輪只產靜態平面／局部樓梯算式與空白工程回覆，未跑瀏覽器、WebGL、轉圖或取得專業／風水核可。
