## 下一輪仍要與屋主確認的取捨

1. **B 主臥面積已決定**：保留原 20m² 目標重排，不採緊湊版，也不縮床／櫃或免除通行。
2. **C 公共空間縮減仍待決定**：已取得兩輪真實 `kimi-k3:cloud` 回覆並獨立反查，不能直接採用其縮家具／門碰櫃的坐標。屋主後續偏好公衛有外窗，因此優先深化前右有窗、客餐保持連通、廚房補原目標的同口徑比較；鞋櫃、照護與防潮仍須一起安排。約 25.3m² 客餐名義面積只是試探，尚未接受縮減或門窗移位。[第二輪反查](c1f-kimi-crosscheck-v2.md)與[外窗防潮條件](c1f-front-window-moisture-v1.md)記錄目前方向。
3. **生活與祭祀資料**：祭拜／陪祀人數、洗衣的樓層偏好、長期照護設備及武轎拆桿／裝桿方式後續再補。沒有這些資料就保留未知，不假造一般尺寸已足夠。

建議工作順序：先核 B／C 騎樓高度敏感度與梯井 → 修 B 武轎／一樓淋浴／套衛缺口 → 合併 C 床位、公衛與廚房 → 同一來源產出 HTML／SVG／3D → 資料檢查及 Windows 目視／互動 → 專業圖說與實物演練。中途若失敗保留原因，不抹掉需求。
