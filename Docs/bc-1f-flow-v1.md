## B：正前方有門，搬轎另走側邊

神桌仍靠私有前廳後側實牆、面向前方；中心 x=2200mm，前方 y=3900mm 新增同中軸 **1800mm 祭祀門**，不加遮擋中軸的屏風。祭拜暫留帶為1800×3200mm，供桌在其後，兩張140×45cm長凳轉向沿左右實牆，避開前門和側門。神桌、供桌與長凳均未縮小。

原先只有側門，不能因此一概說有風水禁忌；同樣也不能把正門對神桌自動判成犯忌。各家的神明／祖先祭祀、坐向與開門習慣不同，本版按已確認的屋主家規安排。道路視線、是否有路沖、梁、背牆管線、香火排煙、補氣不可直吹香爐，以及日常／祭典開門方式仍待家人、祭祀顧問及建築師確認；沒有宣稱風水通過。

180cm前門占中軸後，原240cm候選前窗不能硬塞進剩餘牆面，本版改100cm左側前窗候選；原採光需求不取消，不假設鄰地可開側窗。門開著有光、有風不等於有效採光／通風合格。門扇暫未選型，不把框線當成實際可開淨寬、合規逃生門、防火門或已證明防颱的產品。

搬轎不走祭祀正門，也不繞過供桌。路徑是：

`門外通行帶 → 150cm搬轎側門 → 前段1.6m通道 → 後段1.6m通道 → 150cm收納門 → 武轎收納位`

側門與收納門共用 x=5200mm 軸線，武轎以170cm長向直進直出，不在室內轉彎，不穿神明堂、浴廁或機櫃。藍色虛線與箭頭由模型門、通道及武轎位置導出；不是已演練搬運路徑或固定施工設備。

| 比較 | 本版數值 | 能證明的範圍 |
| --- | --- | --- |
| 武轎收納本體 | 暫估120×170×180cm | 原實物清單規劃值；尚未實測 |
| 側門／收納門 | 各150cm名義開口 | 對120cm本體僅兩側各15cm；門框、全開門扇、把手後淨寬未知 |
| 前後通道 | 各160cm分配寬度 | 按模型兩側各80mm保守暫留，初篩約144cm、單側約12cm；非實際牆厚或完成面 |
| 抬桿與人員 | 未知 | 拆桿可行性、裝桿外廓、扶抬人員、輪具高度、門檻坡度及演練尚未成立 |

本版只初篩收納本體。不能先承諾「一般武轎一定可搬入」。若抬桿不能拆，或必須由人員沿兩側扶抬，須另比較加寬通道／門、前側直入儲藏室，或調整基地；不縮轎、不借騎樓倉儲。本版也沒有把前3.9m當已獲准的裝桿場，臨時祭典通行與裝桿位置仍要確認。

後續實測仍統一填 [實物清單](../inputs/physical-items.json)：`measurements` 量收納外廓；`transport.assembled_dimensions`／`assembled_measurement` 量裝桿搬運外廓；`route_rehearsal` 記錄演練證據。收納已量測不會替裝桿或演練背書。

## C：合併使用，不增加面積

移除餐桌與客廳之間、玄關與客餐區之間的示意隔牆／門框；共用邊分別3200、2000、4000mm全部開放。HTML 與 3D 都保留餐區／客廳／玄關名稱供索引，但共用同一空間群組 `C1-open-living-dining`。

餐區12.8m²＋客廳14.4m²＝27.2m²；連玄關6.4m²為 **6×5.6m、33.6m²**。這些是分配矩形，不是扣牆柱後淨面積。合併沒有新增樓地板、吃掉前3.9m通行帶，或放大6×17.63m假設基地。

家具安排：

- 前側仍放120×80cm四人桌；連椅外廓180×180cm，四周40cm操作帶。原六人桌未容納。
- 180×90cm雙人沙發轉向左側實牆電視，採活動擺位，不冒充靠已取消的隔牆。原240cm三人沙發仍另案。
- 43吋代表電視保持原尺寸，掛左側實牆，與沙發同軸；茶几110×60cm跟隨轉向、沙發前留40cm。90cm單椅靠右後實牆。
- 右側120cm照護帶及150cm轉位暫留不拿來拉餐椅。鞋櫃開門、換鞋仍須與照護通行分時，沒有宣稱無障礙完成。
- 空調改到保留的右側牆，不掛在已拆的餐廳隔牆；仍配既有2F前陽台。折線暫估14.325m、高差1.15m，室外機配對與位置同步重算，不是安裝許可；33.6m²開放空間的負荷、熱回流與排水待專業核對。

孝親房、套衛、廚房、IDF、同軸梯位不動；廚房分隔並未一起拆除。結構柱／剪力牆、梁、樓梯防火區劃、有效採光／通風仍未知。不能把示意模型移除牆當成結構可拆證明；若專業要求保留柱牆，應再重排。

獨立訪客公衛仍未解。原[公衛／採光比較](c-1f-bath-daylight-v1.md)的baseline同步本版；兩個替代案仍未採用，前右公衛案保留自己的分隔及電視牆，不假冒現行開放主案。舊[32坪容量比較](abc-32ping-arcade-v1.md)保留固定歷史骨架，沒有被本版採用。
