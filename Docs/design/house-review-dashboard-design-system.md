# 住宅設計檢核中心 · UI 規格

視覺基準：`Docs/design/house-review-dashboard-concept.png`。

概念稿與實作差異紀錄：`Docs/design/house-review-dashboard-fidelity.md`。

## 資訊架構

- 頂部：版次選擇、匯入新版圖面、匯出會議報告。
- 左側：專案功能與 A／B／C 各樓層樹。
- 首區：基地資料完成度；未知必須是灰色，不能與通過共用顏色。
- 主區：圖面證據、問題標記、右側檢核詳情與下一步責任。
- 下區：跨棟檢核表及上一版到目前版次的幾何／屬性差異。

## Design tokens

- 背景：真白 `#ffffff`；次表面 `#f7f9fb`；選取底 `#e8f2ff`。
- 主文字：`#102a43`；次文字 `#66788a`；邊線 `#d6e0e8`。
- 主動作：teal `#0a7c83`。
- 狀態：失敗 `#c93737`、警告 `#c87912`、通過 `#23834a`、未知 `#8795a1`、專業確認 `#2d6cdf`。
- 圓角：控制 6px、主要邊界 9px；只用 1px 邊線與極少陰影。
- 字體：Noto Sans TC／Microsoft JhengHei／system sans；標題、表格、控制字體皆顯式定義。

## Interaction and accessibility

- 表格列、圖面標記、樓層與主要動作支援鍵盤焦點。
- 點擊檢核列同步更新右側詳情；有棟別／樓層時同步切換圖面。
- 圖面只呈現正規化模型中的可追溯空間；沒有幾何時顯示空狀態，不畫假平面。
- 狀態不只依賴顏色，同時顯示符號與文字。
- 760px 以下改成單欄；列印時隱藏操作控制並保留證據表格。

## Allowed visible copy

住宅設計檢核中心、專案總覽、需求確認、圖面檢核、版次比較、決策紀錄、基地資料完成度、匯入新版圖面、匯出會議報告、檢核事項詳情、跨棟檢核事項總表、下一步行動，以及實際 report JSON 內的版次、問題、證據與責任資料。

不加入行銷標語、假 KPI、無來源通過率、裝飾性 badges 或不在資料中的圖面內容。
