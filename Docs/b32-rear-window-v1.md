## 這版怎麼改

比較框仍為6000×17630mm（約32地坪），前3900mm保留騎樓／通行候選，不改房間或車位。地籍、建蔽、退縮、柱牆與建照未知，這個比較框不是每層可建容量。

1. 公衛移到後左，名義2700×3130mm。較最初約2700×3300mm草排縮深170mm，把家務區展開所需面積留出；不是縮便器、洗手台或淋浴。
2. 1200×1200mm零門檻淋浴在後左；450×700mm原便器旋轉90°、背靠右前牆；600×450mm原洗手台移到後右靠後牆。1500mm乾區轉位圓、旋轉後1200×900mm便器側移預留及指定900×900mm試線均不借淋浴本體；扶手、照護者、膝下、坡度與倒地救援仍未驗證。
3. 浴室後牆畫900mm寬、600mm高、窗台1500mm的候選窗，中心x=1950mm（範圍1500～2400mm），位於洗手台上方、避開左側淋浴。透過既有窗洞檢查重新核對後才同時輸出SVG／HTML／3D；不是只改名稱或拿洗衣窗冒充浴室窗，也不假設側界能開窗。
4. 洗衣機650×650mm前移，600×600mm洗槽靠L形家務區後牆；兩個900×800mm討論操作帶不縮，均留在家務區、不侵入公衛乾通道。兩帶相隔50mm，座標不重疊不代表可兩人同時安全使用。另留出右側家務空間，不新增第二台機器、乾衣機或未核定設備。
5. 公衛以1360mm名義乾通道到達；洗衣凹間為側邊支路，不必穿越洗衣工作站或武轎庫。乾櫃仍1200×450×2100mm，改靠左牆、由右側獨立門進入，保留完整神桌乾背牆，不經洗衣區拿法器。
6. 儲藏改成右後L形，與入口接段同一庫房；不再保留草排13.6m²儲藏卻讓家務僅2.7m²的失衡。神桌、朝街同軸1800mm正門、前左樓梯及二樓以上的全部房間／設備原位不動。

## 門、祭祀與搬轎仍有哪些限制

- 公衛1130mm名義滑門設在前牆偏左，向右表面停放：1230mm停門長、95mm凸出僅產品前討論量。115mm假設門淨寬900mm、乾通道1130mm；試線採先直進再橫移，橫移段距停門凸出預算365mm。關門狀態會阻斷試線，不拿開門結果證明任何門態都可通行。真實門框、把手、軌道、防水、緊急解鎖與輪椅轉彎仍未知。
- 從街門到左乾通道必須經過神明堂祭祀預留區。保留該預留，檢查會明列祭祀佔用狀態的衝突；**不是無人占用就忽略家規，也不是獨立公共／避難通道已核。** 供桌貼神桌、長凳全尺寸停放及家務與祭祀分時仍須家中同意。祭祀坐凳與搬運期間不能沿用日常通行結果。
- 乾櫃1060mm右側內開門，115mm假設830mm；僅用700mm討論本體測局部取物，不宣稱輪椅可進。內開包絡距櫃體僅35mm的討論預算，實門、取物與搬轎須分時；不縮櫃或把門畫穿櫃。
- 武轎1200×1700×1800mm仍是暫估本體，不含裝桿與人員。後門1960mm名義／115mm假設1730mm，前正門1800／1570mm；前門到儲藏的1660mm名義門僅1430mm，側緣通道1450mm。原1500mm連續目標仍差70mm，未解；不因120cm本體試線沒撞就宣稱搬運可行。
- 後門是否有巷子、合法通行權、門外台階／迴轉及拆裝桿仍未知。前備案保持無後門，兩案不互借驗證；所有搬運／祭祀／取物的真人演練未進行。
