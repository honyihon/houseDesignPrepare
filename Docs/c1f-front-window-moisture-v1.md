# C 一樓有窗公衛：屋主偏好與防潮設計條件

2026-10-13。屋主回覆：「如果有外窗的會比較好 避免後續生黴菌之問題」。因此**前右有窗公衛升為下一版優先深化方向**，無窗案保留作比較，不再作目前首選。

這是外窗的優先偏好，不擅自改成「沒有外窗就絕對不能接受」，也不是接受客餐縮減、移大門／前窗或採用整案。原 ABC 主案、舊比較 HTML／3D、需求與兩輪真實模型對話均未改寫。[機器可讀的偏好與防潮條件](../inputs/c1f-window-moisture-brief.json)另存，不影響封存對話雜湊。

## 外窗有幫助，但不能單靠它防黴

[EPA 防黴／水分指引](https://www.epa.gov/mold/brief-guide-mold-moisture-and-your-home)將水分控制列為核心，建議處理漏水、適時開窗／排氣，必要時除濕；一般室內相對濕度建議低於 60%，理想 30–50%。這是一般居住指引，**不是台灣建築法規或本案驗收標準**。

本案的設計推論：可開外窗能增加排濕選項與日常觀察，但騎樓遮蔽、雨天、室外潮濕、住戶關窗與漏水都會影響結果。不能用「有日光」「畫出窗框」或「防黴材料」當成永不發黴的保證。

| 分區／項目 | 下一版比較基準 |
| --- | --- |
| 訪客公衛 | 前右 `[4000,3900,2000,1800]`，名義 3.6m²；普通馬桶與洗手台，不加淋浴、不宣稱無障礙已完成 |
| 玄關／乾式前室 | `[4000,5700,2000,1800]`，名義 3.6m²，保留 120cm 鞋櫃；仍未達舊玄關 6.5m² 目標 |
| 客餐廳 | 保開放連通，名義約 **25.3m²**；新增牆柱與完成面尚未扣除，縮減未獲屋主採用 |
| 廚房 | 依既有討論口徑補原 6.5m² 目標；原尺寸廚具／冰箱保留，分時操作問題仍須處理 |
| 孝親照護 | 保側牆床／後窗與原套衛淋浴方向，不以縮床、縮淋浴、刪照護來塞公衛 |

門、窗、轉位與家具要從**同一份合併比較資料**重新生成 HTML／SVG／3D。不能把舊公衛案疊上側牆床，就標整案通過。

## 外窗怎樣預留

- 優先**可開啟的前側高窗**，兼顧隱私與採光；不增加側窗，因側界／共壁未確認。
- 目前占位 **600 × 500mm、窗台 2100mm**，只是上一輪比較用的尺寸，不是最終產品、有效開口或法規認定。玻璃、紗網、開啟角度與遮蔽都要納入實際通風評估。
- 高窗不能要求長輩踩椅子開關；把可及控制、清潔與換修方式一起設計。外開窗扇不得以示意圖預設侵占騎樓通行。
- 外側必須確實與戶外有空氣交換，不把封閉前室／密閉陽台當「外窗已成立」。前方騎樓遮雨仍要核對風雨倒灌、滴水與噪音／灰塵條件。
- 餐廳前窗、大門和公衛窗一起畫前立面；目前餐窗移位後的 100mm 名義框距不能視為結構已解。門框、柱位與窗台排水由建築師核對，不為外窗硬切梁柱。

## 同時列入的防潮措施

以下是本案待設計清單，不是已施工措施，也不是由 EPA 核定本案細節：

| 面向 | 設計要求／要取得的證據 |
| --- | --- |
| 獨立排氣 | 仍設計可檢修的公衛排氣，確認合法戶外出口、回流防止、噪音與實際風量；不排進天花板，也不接廚房排油煙或 IDF 排風。 |
| 補氣 | 有排氣必須一起核補氣途徑；不單靠氣密門／窗關閉時的偶然縫隙，不把污染空氣導向餐廳。 |
| 自動控制 | 研究濕度感測與延遲停機，降低忘記開扇／關窗的影響。風量、控制濕度與延時待產品與現場乾燥測試，不預設幾分鐘就夠。 |
| 雨水與漏水 | 窗框防雨、窗台向外排水、滴水、防水接縫、管穿與地坪構造須有詳圖；窗框及水管漏水不能由排氣扇補救。 |
| 結露 | 冷水管、冷氣冷凝水、窗框及冷熱交界要核保溫／排水與檢修；不將冷凝水藏在密閉櫃或封死的天花板。 |
| 清潔維護 | 材料、接縫、紗網、排氣止回與管道檢修口可清潔、更換；不以「防黴漆」代替乾燥與修漏。 |
| 實際使用 | 入住後能觀察濕度與窗／牆結露；下雨或室外潮濕時，不預設一直開窗必然更乾。必要時配合除濕，不能只把責任留給住戶天天開窗。 |

普通公衛不加淋浴，但氣候、擦洗、管漏與窗框進水仍須控制；孝親套衛的排濕／防水則要另外驗證，不能因新公衛有外窗就認定後段衛浴也已處理。
