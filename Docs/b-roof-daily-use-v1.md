# B屋頂日常使用、24㎡容量與前門到達

2026-11-10。[日常兩案與容量圖](../structured/coordination/b-roof-daily-use-v1/index.html)。沿S1／S2相同設備與R1天井預留，加入同尺寸晾衣架、折衣桌及RF前門到達的獨立研究。原ABC／3D、所有B搬轎／上層比較、RF原快照及正式需求保留。這次不改主圖、不採用較小平台，也沒有收到真實基地或產品資料。

## 固定前帶無法靠移設備補成24㎡

原6000×3900mm前帶名義外框23.4㎡，已比24㎡目標少0.6㎡。只扣本輪115mm外緣、尚不扣設備、門片、內側交界牆及通路的樂觀上界為**21.83945㎡**，仍少2.16055㎡。這是固定前帶的必要容量界，不是所有整棟重排都不可能的證明。

依現行完整祭祀／乾背保護投影及梯核，屋頂前後在不穿保護區的條件下是兩個分開的區塊。後側即使有空地，也沒有本輪已允許的日常路徑可和前側相加。必要巡檢與日常曬衣仍分開；不宣稱所有傳統風水都禁止通行，而是沿專案現行RF低活動、非日常保護用途。

向道路或鄰地外伸、在RF再加一層、用抬高橋跨過祭祀上方、取消三樓工作天井或挪動一樓神明堂，都不是本輪可直接採用的小改。若24㎡不能取捨，需要把一樓保護位置、全棟樓梯與上層功能一併交建築師研究，不能只在屋頂畫一個面積數字。原24㎡與10㎡下限均保留；下限不是已同意的新目標。

## D1與D2先看能否日常操作

兩案都加入代表1800×600mm移動晾衣架，以及1200×450mm折衣桌，每件另留700mm操作深度。它們是可替換的試排尺寸，不是選定產品、曬被容量、桿高或防颱固定；不增加洗衣機、濕台或地排，也不移走原一樓洗衣需求。

桌架機身與操作輪廓均避列明設備整組預留。D1的折衣操作和700mm到達試線共用，不能宣稱有人折衣時另一人仍可通行；操作區也不能再重算成專用空間。D2桌位減少這種共用，但不會解決後設備緊迫。衣籃、衣物及家具不得堵住唯一前門通路，實際操作與多人錯身仍未核。

保留兩個面積口徑：上輪設備／門扣除後的前開放輪廓，以及本輪再扣代表桌架機身的輪廓，均含共用通路。它們不是法定有效面積或完整可用平台；狹長餘塊、晾衣展開及實際風雨仍須功能審查，不以扣家具數字宣稱法規不符或10㎡下限已核。

## RF前門與樓梯到達不能只看門寬

來源RF圖的全寬到達板為2200×1000mm，但前一層最後一跑位於右側。本輪保守只用**右側1000×1000mm到達平台**接RF前門，不把梯井或左半部當隨時可走的地板。平台前端與名義RF前牆相差70mm，這段銜接、同標高及門檻仍是候選條件，未證明既有樓板與梯段真的相接。

前門名義1130mm，兩側各115mm框／完成面預算後有900mm；門中心與保守平台中心卻相差65mm。指定折線以700／800mm方塊可在條件地面內通行，**900mm折線會向平台左側超出15mm**。這不是證明所有900mm走法都不可能，而是目前這條路不能用名義門寬當作全程900mm完成。

原RF候選前門的**右鉸鏈門全開仍卡到外側轉彎試線**。本輪保同一1130mm洞，改左鉸鏈作改善案，原右開門資料留作對照；與一樓祭祀正門無關。門全開、半開、關閉逐態檢查；左開門只有全開時指定700mm到達試線不碰門片。

門片0～90度每15度取樣未碰列明桌架或設備，不等於完整五金、把手、風壓、門檻、防雨、上鎖或逃生認證。真正3F至RF的梯段、梁底、扶手、淨高、到達標高與消防仍未核，沒有新增五樓。

若來源所畫的2200mm全寬到達板能由建築師確認為可用平地，這條900mm折線在另一個全寬候選模型內可容納；不能直接把左半部永久判成洞。現在沒有結構與到達資料，因此兩種口徑分列。要把900mm連續淨寬作正式目標，先確認全寬平台；若不成立再調整平台與門組，用實際完成面回套。700／800mm只是本輪幾何試線，不是法定維修寬、照護、整機拆運或輪椅通行核可。

## 建議接下來怎麼決定

先保D1／D2功能圖與24㎡缺口，設備條件到齊後以同版包絡回套；D1適合先核設備檢修，D2適合比較家務便利，不直接稱其中一個已能施工。若屋主後續接受較小但可操作的前平台，仍須明確更新需求及做專業核對；本輪沒有替屋主作這個選擇。

若24㎡不可讓步，應開整棟重大重排研究，不能再把時間花在同一塊前帶微移機器。本包附決策路徑及工程回覆空白表，先分清這兩種工作範圍，實際資料到齊後才正式鎖案。A設計師及C照護需求不拿來暗補B缺口。

本輪只做來源雜湊、條件平面、門態、方塊與面積檢查；不跑瀏覽器、WebGL或轉圖。結構、法規、風水、產品、通風、噪音、防水與施工核可仍未知。
