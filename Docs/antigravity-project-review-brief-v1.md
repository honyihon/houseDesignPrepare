- 風水依屋主明確家規檢視，不捏造「通用科學標準」或保證全派別接受。B 要保朝街中軸門，並避免背牆另一側樓梯／梯廳及整個神明堂上方的不允許用途；C 目前接受避床體上方濕區，不要求整間臥室都避開。

- 外窗不等於不會發霉；仍看窗外空間、有效開口、防水、排風、補氣、冷凝與維修。沒有選機與現場資料時只能列待驗證。
- 每側 80mm 模型內縮、名義門寬、跑步機後 2m／側 50cm 等都是討論假設。牆柱、完成面、原廠手冊與人體演練未確認，不是通過證據。
- 已明列的停車不足、KTV／設備未排、C 客房低於原面積目標、B 主臥牆厚餘量等，先分類為「已知未解需求」。只有文件／畫面錯稱已解、需求被刪或你找到新的漏算，才另外列新缺陷。已知項仍可提出較好的最小修改方案。
- 程式缺陷須提供具體輸入條件、呼叫／資料流、檔案行號、可觀察結果及低風險修法，不能只寫「建議多測試」。設計疑慮須指明方案／棟／樓／房間、尺寸來源與代價，不能以兩模型同意取代專業簽證。
