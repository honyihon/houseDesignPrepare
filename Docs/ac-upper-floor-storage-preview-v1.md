# A／C六層同版加櫃3D比較

2026-11-12。[併入前核對](abc-upper-floor-storage-merge-v1.md)確認A／C六層相符後，現在已將六件櫃體加入同版完整場景的比較副本。[開3D比較](../structured/coordination/ac-storage-preview-v1/index.html)／[同版平面目錄](../structured/coordination/ac-storage-preview-v1/plans.html)／[離線ZIP](../structured/coordination/ac-storage-preview-v1/ac-storage-preview.zip)。原ABC入口、已驗收獨立收納檢視及其ZIP維持原樣。

先選A或C，再選2F／3F／RF，可以切「原配置對照／加櫃比較」、看完整樓層或看新增櫃體。橙色是本次新增，原房界、家具、門窗、樓梯、空調及機電背景保留；原配置沒有偷加櫃，新增版也沒有縮減原家具。每層連到該版本的平面，編號附可見中文品名圖例。

顯示第2版預設「全部品名」，此時可另開關家具名稱；明確選「重點品名」時，家具名稱勾選框維持停用，旁邊有說明。第1輪MAXMXt的25項來源與當時檔案相符，首個A2桌機案例已通過來源、品名、平面連結及實際櫃體尺寸／標高／像素四項檢查，但程式把預設選單改回重點模式，驗收直接取消已停用的勾選框而逾時。瀏覽器已關閉，其他案例未完成；結果與兩張截圖另存，不改成passed。

第2版只修正比較副本的品名預設與說明，並讓驗收經正常選單先切到全部品名、確認勾選框可操作後才測開關。原家具、六件櫃體及門窗／樓梯等資料均保持；不強制點擊、不移除disabled、不放寬尺寸或像素門檻。結果另記選單值、勾選框是否停用／勾選及實際可見家具標籤，若再失敗可直接辨識控制狀態。

第2輪r23BET的25項來源相符，130項檢查通過、完成16個案例：桌機12個，手機A2／A3原配置與加櫃4個。手機A-RF初次特寫寬157.5px，已通過尺寸及像素檢查；關閉家具品名並收合側欄後，量測時`focusPending:true`，畫面仍處在整間平台的過渡取景，櫃體寬39.8px而失敗。實際900×450×900mm與+10m標高保持，主控台沒有錯誤、瀏覽器已關閉。原結果及26張截圖保留，僅目視本次A-RF手機特寫與失敗畫面，其他截圖未逐張審閱。

顯示第3版讓側欄縮放與櫃體重取景在同一次更新完成，去掉中間等待下一幀的整間平台畫面。每次實際繪圖後記錄視口、可用畫面區、相機及品名狀態；驗收等連續兩次畫面已繪出相同狀態、沒有待處理縮放後才量測。仍核原55px寬／60px高／5000px²面積及原像素門檻，並額外拒絕尚未更新的畫面，不延長逾時、不重試、不強制操作。

這裡使用原3D已有的概念牆、開口、家具與標高作背景，並非新增實測高度。1F保持來源原配置，本輪沒有把C其他照護／浴室續案默認合進來。RF只放耐候工具／備品；產品、固定、防雨、防鏽、荷重、結露與維修仍未知。B P4／Q3與RF尚需整層同步，所以B不放入這個比較，不代表取消後門預案、前門備案或原RF24㎡目標。

新增採用既有模型資料與HTML副本的局部修補，不跑整套模型生成器、求解器、瀏覽器或WebGL。檔案核對會反向移除六個新增物件，確認能回到完整原模型；原房間、設備、家具及定位皆逐項保留。原配置與新增版共四個棟別／狀態、16個棟層狀態，對應16張可離線閱讀的平面。
