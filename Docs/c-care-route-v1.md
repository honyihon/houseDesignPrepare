## 檢查範圍與結果

概念外框仍6000×17630mm，前緣騎樓區深3900mm；不是對32坪基地的可建面積或騎樓法規核定。沒有新增／縮小任何房間分區，C 2F～RF 原樣保留。

試線起點 `[3285,3000]` 在騎樓**內部**，不是道路／路緣。以900×900mm矩形，沿指定正交連續路徑到床邊，再到私人衛浴門內指定停點。檢查同時納入實際雙側洞口、115mm討論門邊預算、牆段、家具本體、公共家具操作、樓梯本體及實際門片；不是只靠房間相鄰或折線穿牆。

| 狀態 | 騎樓內點→床邊 | 床邊→套衛門內 |
| --- | --- | --- |
| 上版控制（兩道私人門全開） | 仍有朝街門、客餐門及沙發阻擋 | 指定局部試線無衝突 |
| 新案三門全開 | 指定矩形試線無衝突 | 指定矩形試線無衝突 |
| 只關朝街門 | 只被朝街門片阻擋 | 無衝突 |
| 只關孝親房門 | 只被房門片阻擋 | 無衝突 |
| 只關浴室門 | 無衝突 | 只被浴室門片阻擋 |

關門是必要反例，不是可通行。原1500mm臥室迴轉預留及房門避床體正投影保留，未宣稱風水核可。前室獨立1470mm假設淨深仍不足1500mm，不冒充新增迴轉能力。

朝街門使用一般暫估1050×80×2100mm單扇外廓及同一固定鉸點，0°／90°由剛體轉換導出；不是兩張任意縮放矩形。另以每個角點在0～90°的解析極值求保守掃掠包絡，不只抽查數個角度。包絡約 `[2774.24,3900,1090.76,1090.76]`，不伸入騎樓、不撞家具本體及公共操作。橙色虛線是**保守包絡**，不是產品弧線或門把淨空核可。

2400mm前窗同尺寸同位置保留，門窗名義洞口間預留100mm；全開門片與假設右完成面僅約20mm，不能推定足夠裝把手／止擋。門框、門把、開角、防夾、氣密、水密、結構邊框及門檻皆須產品與專業確認。

## 仍需專業及實物確認

1. **門的開向與防火分隔**：向內開是避免占公共騎樓的概念，不保證消防合法。若要求外開，建議另比較退縮門斗並明列室內面積代價，不直接將門片伸入公共通行區。樓梯本體原1000mm分隔門不在照護路徑中，但它的開向、消防認證及淨高仍未知，不能開進照護通路。
2. **全程照護／救援**：900mm矩形能平移不代表輪椅轉向、雙人照護或倒地救援可完成；道路高差、騎樓坡度、地坪、門檻、門鎖等不在本輪幾何證明內。
3. **私人衛浴**：仍須穿孝親房進套衛；原「照服員可從公共通道直達」偏好未滿足。前方訪客公衛獨立保留，兩項不可混為一談。完整浴室轉位、扶手及通風／防水仍未核。
4. **IDF、面積與工作陽台**：前室是共享通行，IDF獨立機房面積信用仍為0；原4m²／4.8m²工作陽台、房間目標與部分80mm家具牆邊預留等未因動線改善而消除。仍只有一台既有2F洗衣機。
5. **家具日常操作**：餐桌400mm四周及沙發／閱覽椅600mm前方僅為原討論預留，非高齡者起坐、人體活動或通行法定尺寸；仍須帶實物及人員演練。新路線與這些預留不重疊，不藉刪掉操作區通過檢查。
