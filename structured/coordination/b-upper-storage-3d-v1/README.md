# B同版上層與收納3D比較

解壓整包開[index.html](index.html)，或[同版平面](plans.html)。不需WSL、Node、網路或伺服器。

四樓層版本各有原配置／加櫃，保多邊形房界、二樓L形到達、Q3上下層梯及RF開口；可看收納、整層、樓梯、俯視及完整品名。

只有新增櫃與尺寸相符的來源概念家具用指定高度；其餘只畫原平面投影。房界線框是辨識標示，不是真實牆高／厚度。樓梯沒有補造梁板或扶手，也不代表淨高與結構核可。

顯示第2版把二樓梯標籤改為「一樓原梯接Q3上層改梯」，不改來源幾何；原P4房間名稱留在來源JSON作追溯，不直接當成改梯後的畫面說明。

一樓兩入口各三態另有原同版平面，本3D不合併一樓。RF24㎡原目標仍缺，P4排水與聲學／結構／新風／產品待核。新畫面待屋主另驗，不沿用TQX7gQ第1版、A／C或其他已驗收檢視的passed。
